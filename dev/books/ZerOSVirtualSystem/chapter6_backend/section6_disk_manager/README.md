# 第6.6节：磁盘管理服务

## 本节导读

磁盘管理服务负责 ZerOS 虚拟磁盘的分区创建、删除、合并等操作。本节详细讲解 DISKMANAGER 服务的职责与接口、分区操作与配额管理的实现。

1. 理解 DISKMANAGER 服务的职责

3. 理解配额管理的实现方式
