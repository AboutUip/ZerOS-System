## 一、分区创建实现

### 1.1 创建流程

```
接收创建请求
      │
      ▼
校验参数（drive, label, quota）
      │
      ▼
检查分区是否已存在
      │
      ▼
创建物理目录
      │
      ▼
更新 DiskData.json
      │
      ▼
返回结果
```

### 1.2 实现代码

```php
<?php
// system/service/DISKMANAGER.php

require_once __DIR__ . '/jwtVerify.php';
requireJWTVerify('DISKMANAGER');

function handleCreatePartition() {
    // 1. 获取参数
    $drive = $_POST['drive'] ?? '';
    $label = $_POST['label'] ?? '';
    $quota = intval($_POST['quota'] ?? 0);
    
    // 2. 参数校验
    if (empty($drive)) {
        sendResponse(false, '缺少盘符', null, 400);
    }
    
    // 盘符格式校验（A-Z:）
    if (!preg_match('/^[A-Z]:$/i', $drive)) {
        sendResponse(false, '无效的盘符', null, 400);
    }
    
    // 3. 转换为大写
    $drive = strtoupper($drive);
    
    // 4. 检查是否已存在
    $diskData = loadDiskData();
    if (isset($diskData['partitions'][$drive])) {
        sendResponse(false, '分区已存在', null, 400);
    }
    
    // 5. 禁止创建系统分区
    if ($drive === 'C:' || $drive === 'D:') {
        // C: 和 D: 是系统分区，禁止手动创建
        sendResponse(false, '系统分区禁止创建', null, 403);
    }
    
    // 6. 创建物理目录
    $physicalPath = DISK_BASE_PATH . '/' . $drive;
    if (!mkdir($physicalPath, 0755, true)) {
        sendResponse(false, '创建目录失败', null, 500);
    }
    
    // 7. 更新 DiskData.json
    $diskData['partitions'][$drive] = [
        'label' => $label ?: '新分区',
        'quota' => $quota,
        'createdAt' => time(),
        'fileCount' => 0
    ];
    
    saveDiskData($diskData);
    
    // 8. 返回结果
    sendResponse(true, '分区创建成功', [
        'drive' => $drive,
        'label' => $label ?: '新分区',
        'quota' => $quota,
        'createdAt' => time()
    ]);
}
```

## 二、分区删除实现

### 2.1 删除流程

```
接收删除请求
      │
      ▼
校验盘符
      │
      ▼
检查是否是系统分区
      │
      ▼
检查分区是否为空
      │
      ▼
删除物理目录
      │
      ▼
更新 DiskData.json
      │
      ▼
返回结果
```

### 2.2 实现代码

```php
function handleDeletePartition() {
    $drive = $_POST['drive'] ?? '';
    
    // 参数校验
    if (empty($drive)) {
        sendResponse(false, '缺少盘符', null, 400);
    }
    
    $drive = strtoupper($drive);
    
    // 禁止删除系统分区
    if ($drive === 'C:' || $drive === 'D:') {
        sendResponse(false, '系统分区禁止删除', null, 403);
    }
    
    // 加载磁盘数据
    $diskData = loadDiskData();
    
    // 检查分区是否存在
    if (!isset($diskData['partitions'][$drive])) {
        sendResponse(false, '分区不存在', null, 404);
    }
    
    // 检查分区是否为空
    $physicalPath = DISK_BASE_PATH . '/' . $drive;
    $files = scandir($physicalPath);
    $nonDotFiles = array_filter($files, function($f) {
        return $f !== '.' && $f !== '..';
    });
    
    if (count($nonDotFiles) > 0) {
        sendResponse(false, '分区非空，无法删除', null, 400);
    }
    
    // 删除物理目录
    if (!rmdir($physicalPath)) {
        sendResponse(false, '删除目录失败', null, 500);
    }
    
    // 更新 DiskData.json
    unset($diskData['partitions'][$drive]);
    saveDiskData($diskData);
    
    sendResponse(true, '分区删除成功', ['drive' => $drive]);
}
```

## 三、配额管理

### 3.1 配额检查

在 FSDirve 写入文件前检查配额：

```php
function checkQuota($drive) {
    $diskData = loadDiskData();
    $partition = $diskData['partitions'][$drive] ?? null;
    
    if (!$partition) {
        return ['allowed' => true]; // 分区不存在，跳过检查
    }
    
    $quota = $partition['quota'] ?? 0;
    
    // 0 表示无限制
    if ($quota === 0) {
        return ['allowed' => true];
    }
    
    // 计算当前使用量
    $physicalPath = DISK_BASE_PATH . '/' . $drive;
    $used = calculateDirectorySize($physicalPath);
    
    return [
        'allowed' => $used < $quota,
        'used' => $used,
        'quota' => $quota,
        'available' => $quota - $used
    ];
}

function calculateDirectorySize($dir) {
    $size = 0;
    
    if (!is_dir($dir)) {
        return filesize($dir);
    }
    
    $files = scandir($dir);
    foreach ($files as $file) {
        if ($file === '.' || $file === '..') continue;
        
        $path = $dir . '/' . $file;
        
        if (is_dir($path)) {
            $size += calculateDirectorySize($path);
        } else {
            $size += filesize($path);
        }
    }
    
    return $size;
}
```

### 3.2 写入前配额检查


## 四、空间统计

### 4.1 获取分区使用情况

```php
function getPartitionUsage($drive) {
    $physicalPath = DISK_BASE_PATH . '/' . $drive;
    
    if (!is_dir($physicalPath)) {
        return null;
    }
    
    $used = calculateDirectorySize($physicalPath);
    
    // 加载磁盘数据获取配额
    $diskData = loadDiskData();
    $partition = $diskData['partitions'][$drive] ?? [];
    $quota = $partition['quota'] ?? 0;
    
    return [
        'drive' => $drive,
        'label' => $partition['label'] ?? '',
        'used' => $used,
        'quota' => $quota,
        'available' => $quota > 0 ? max(0, $quota - $used) : -1, // -1 表示无限制
        'total' => $quota > 0 ? $quota : $used
    ];
}
```

## 本节小结

本节讲解了分区操作与配额管理的实现：

1. **创建分区**：校验参数 → 检查存在性 → 创建目录 → 更新元数据
2. **删除分区**：校验 → 检查系统分区 → 检查空目录 → 删除 → 更新元数据
3. **配额检查**：写入前计算已用空间，比较配额限制
4. **空间统计**：递归计算目录大小，返回使用情况
