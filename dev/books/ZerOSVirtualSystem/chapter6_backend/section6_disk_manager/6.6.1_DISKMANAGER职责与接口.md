# 6.6.1 DISKMANAGER 职责与接口

## 本节导读

本节使读者能够：**① 理解 DISKMANAGER 服务的职责——管理 ZerOS 的虚拟磁盘分区，包括创建、删除、查询等操作；② 掌握服务提供的核心接口；③ 理解磁盘分区的存储结构——DiskData.json。** 源码位置：`system/service/DISKMANAGER.php`。

---

## 一、服务概述

### 1.1 职责

DISKMANAGER 是 ZerOS 后端的磁盘管理服务，负责：
- **分区管理**：创建、删除虚拟磁盘分区
- **分区信息查询**：获取分区列表、空间使用情况
- **配额管理**：限制分区的最大容量
- **磁盘初始化**：系统首次安装时的磁盘设置

### 1.2 访问地址

```
POST /system/service/DISKMANAGER.php?action=xxx
```

---

## 二、接口规范

### 2.1 创建分区 (create_partition)

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | string | 是 | `create_partition` |
| drive | string | 是 | 盘符（如 `E:`） |
| label | string | 否 | 分区标签 |
| quota | number | 否 | 最大容量（字节），0 表示无限制 |

**响应**：

```json
{
    "success": true,
    "message": "分区创建成功",
    "data": {
        "drive": "E:",
        "label": "数据盘",
        "quota": 10737418240,
        "createdAt": 1701234567
    }
}
```

### 2.2 删除分区 (delete_partition)

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | string | 是 | `delete_partition` |
| drive | string | 是 | 盘符（如 `E:`） |

### 2.3 列出分区 (list_partitions)

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | string | 是 | `list_partitions` |

**响应**：

```json
{
    "success": true,
    "data": {
        "partitions": [
            {
                "drive": "C:",
                "label": "系统盘",
                "quota": 0,
                "used": 536870912,
                "available": 1073741824,
                "total": 1610612736,
                "createdAt": 1700000000
            },
            {
                "drive": "D:",
                "label": "数据盘",
                "quota": 10737418240,
                "used": 2147483648,
                "available": 8589934592,
                "total": 10737418240,
                "createdAt": 1701234567
            }
        ]
    }
}
```

### 2.4 获取分区信息 (get_partition_info)

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | string | 是 | `get_partition_info` |
| drive | string | 是 | 盘符（如 `D:`） |

## 三、存储结构

### 3.1 DiskData.json

分区元数据存储在 `DISK/D/DiskData.json`：

```json
{
    "partitions": {
        "C:": {
            "label": "系统盘",
            "quota": 0,
            "createdAt": 1700000000,
            "fileCount": 150
        },
        "D:": {
            "label": "数据盘",
            "quota": 10737418240,
            "createdAt": 1701234567,
            "fileCount": 500
        }
    },
    "lastModified": 1701234567
}
```

---

## 本节小结

本节讲解了 DISKMANAGER 服务的职责与接口：

1. **创建分区**：指定盘符、标签、配额
2. **删除分区**：删除指定盘符
3. **列出分区**：返回所有分区信息
4. **获取分区信息**：返回单个分区的详细信息
