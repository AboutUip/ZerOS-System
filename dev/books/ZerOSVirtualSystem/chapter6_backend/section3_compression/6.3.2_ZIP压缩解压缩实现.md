## 一、PHP ZipArchive 简介

```php
$zip = new ZipArchive();
$zip->open('archive.zip', ZipArchive::CREATE);  // 创建或打开

$zip->close();
```

## 二、压缩实现 (compress)

### 2.1 压缩流程

```
接收压缩请求
      │
      ▼
校验参数（sourcePaths, targetPath）
      │
      ▼
创建目标 ZIP 文件
      │
      ▼
遍历源路径，逐个添加文件
      │
      ▼
关闭 ZIP 文件
      │
      ▼
返回压缩结果
```

### 2.2 实现代码

```php
<?php
// system/service/CompressionDirve.php

require_once __DIR__ . '/jwtVerify.php';
requireJWTVerify('CompressionDirve');

function handleCompress() {
    // 1. 获取参数
    $sourcePaths = json_decode($_POST['sourcePaths'] ?? '[]', true);
    $targetPath = $_POST['targetPath'] ?? '';
    $basePath = $_POST['basePath'] ?? '';
    
    // 2. 参数校验
    if (empty($sourcePaths)) {
        sendResponse(false, '缺少源路径', null, 400);
    }
    if (empty($targetPath)) {
        sendResponse(false, '缺少目标路径', null, 400);
    }
    
    // 3. 路径转换
    $targetPhysical = virtualToPhysical($targetPath);
    
    // 4. 创建 ZIP 文件
    $zip = new ZipArchive();
    $result = $zip->open($targetPhysical, ZipArchive::CREATE | ZipArchive::OVERWRITE);
    
    if ($result !== true) {
        sendResponse(false, '创建 ZIP 文件失败，错误码: ' . $result, null, 500);
    }
    
    // 5. 添加文件
    $fileCount = 0;
    foreach ($sourcePaths as $sourcePath) {
        $sourcePhysical = virtualToPhysical($sourcePath);
        
        if (is_dir($sourcePhysical)) {
            // 目录：递归添加
            $fileCount += addDirectoryToZip($zip, $sourcePhysical, $basePath);
        } elseif (is_file($sourcePhysical)) {
            // 文件：直接添加
            $zipName = basename($sourcePath);
            $zip->addFile($sourcePhysical, $zipName);
            $fileCount++;
        }
    }
    
    // 6. 关闭 ZIP
    $zip->close();
    
    // 7. 返回结果
    sendResponse(true, '压缩成功', [
        'path' => $targetPath,
        'size' => filesize($targetPhysical),
        'fileCount' => $fileCount
    ]);
}

function addDirectoryToZip($zip, $dirPath, $basePath, $prefix = '') {
    $count = 0;
    $files = scandir($dirPath);
    
    foreach ($files as $file) {
        if ($file === '.' || $file === '..') continue;
        
        $filePath = $dirPath . '/' . $file;
        $zipName = $prefix ? $prefix . '/' . $file : $file;
        
        if (is_dir($filePath)) {
            $count += addDirectoryToZip($zip, $filePath, $basePath, $zipName);
        } else {
            $zip->addFile($filePath, $zipName);
            $count++;
        }
    }
    
    return $count;
}
```

### 2.3 关键细节

- **ZipArchive::CREATE**：如果不存在则创建
- **ZipArchive::OVERWRITE**：如果存在则覆盖
- **目录递归**：使用递归函数处理目录结构
- **路径前缀**：保留目录层级结构

## 三、解压缩实现 (decompress)

### 3.1 解压流程

```
接收解压请求
      │
      ▼
校验参数（archivePath, targetPath）
      │
      ▼
打开 ZIP 文件
      │
      ▼
创建目标目录（如不存在）
      │
      ▼
逐个解压文件
      │
      ▼
处理覆盖选项
      │
      ▼
关闭 ZIP，返回结果
```

### 3.2 实现代码

```php
function handleDecompress() {
    // 1. 获取参数
    $archivePath = $_POST['archivePath'] ?? '';
    $targetPath = $_POST['targetPath'] ?? '';
    $overwrite = ($_POST['overwrite'] ?? 'false') === 'true';
    
    // 2. 参数校验
    if (empty($archivePath)) {
        sendResponse(false, '缺少压缩包路径', null, 400);
    }
    if (empty($targetPath)) {
        sendResponse(false, '缺少目标路径', null, 400);
    }
    
    // 3. 路径转换
    $archivePhysical = virtualToPhysical($archivePath);
    $targetPhysical = virtualToPhysical($targetPath);
    
    // 4. 检查 ZIP 文件
    if (!file_exists($archivePhysical)) {
        sendResponse(false, '压缩包不存在', null, 404);
    }
    
    // 5. 创建目标目录
    if (!is_dir($targetPhysical)) {
        mkdir($targetPhysical, 0755, true);
    }
    
    // 6. 打开 ZIP
    $zip = new ZipArchive();
    $result = $zip->open($archivePhysical);
    
    if ($result !== true) {
        sendResponse(false, '打开 ZIP 文件失败', null, 500);
    }
    
    // 7. 解压文件
    $fileCount = 0;
    $totalSize = 0;
    
    for ($i = 0; $i < $zip->numFiles; $i++) {
        $fileName = $zip->getNameIndex($i);
        
        // 跳过目录
        if (substr($fileName, -1) === '/') {
            continue;
        }
        
        $targetFile = $targetPhysical . '/' . $fileName;
        $targetDir = dirname($targetFile);
        
        // 创建子目录
        if (!is_dir($targetDir)) {
            mkdir($targetDir, 0755, true);
        }
        
        // 检查是否覆盖
        if (file_exists($targetFile) && !$overwrite) {
            continue;
        }
        
        // 解压文件
        $content = $zip->getFromIndex($i);
        if ($content !== false) {
            file_put_contents($targetFile, $content);
            $fileCount++;
            $totalSize += strlen($content);
        }
    }
    
    // 8. 关闭 ZIP
    $zip->close();
    
    // 9. 返回结果
    sendResponse(true, '解压成功', [
        'extractedPath' => $targetPath,
        'fileCount' => $fileCount,
        'totalSize' => $totalSize
    ]);
}
```

### 3.3 边界处理

- **目录跳过**：ZIP 中的目录条目不需要解压
- **子目录创建**：解压时需要逐级创建目录
- **覆盖选项**：根据 overwrite 参数决定是否覆盖
- **路径安全**：防止 `../../../` 路径穿越攻击

## 四、列表实现 (list)

### 4.1 列表流程

```
接收列表请求
      │
      ▼
打开 ZIP 文件
      │
      ▼
遍历所有文件
      │
      ▼
收集文件信息
      │
      ▼
返回文件列表
```

### 4.2 实现代码

```php
function handleList() {
    // 1. 获取参数
    $archivePath = $_POST['archivePath'] ?? '';
    
    // 2. 参数校验
    if (empty($archivePath)) {
        sendResponse(false, '缺少压缩包路径', null, 400);
    }
    
    // 3. 路径转换
    $archivePhysical = virtualToPhysical($archivePath);
    
    // 4. 检查文件
    if (!file_exists($archivePhysical)) {
        sendResponse(false, '压缩包不存在', null, 404);
    }
    
    // 5. 打开 ZIP
    $zip = new ZipArchive();
    $result = $zip->open($archivePhysical);
    
    if ($result !== true) {
        sendResponse(false, '打开 ZIP 文件失败', null, 500);
    }
    
    // 6. 遍历文件
    $files = [];
    $totalSize = 0;
    $compressedSize = 0;
    
    for ($i = 0; $i < $zip->numFiles; $i++) {
        $stat = $zip->statIndex($i);
        
        $files[] = [
            'name' => $stat['name'],
            'size' => $stat['size'],
            'compressedSize' => $stat['comp_size'],
            'modified' => $stat['mtime']
        ];
        
        $totalSize += $stat['size'];
        $compressedSize += $stat['comp_size'];
    }
    
    // 7. 关闭 ZIP
    $zip->close();
    
    // 8. 返回结果
    sendResponse(true, '查询成功', [
        'path' => $archivePath,
        'files' => $files,
        'totalSize' => $totalSize,
        'compressedSize' => $compressedSize
    ]);
}
```

## 五、Python 实现 (使用 zipfile)

```python
# system/service/backend-python/FSDriver.py (压缩相关部分)

import zipfile
from pathlib import Path

def compress(self, source_paths, target_path, base_path=None):
    """压缩文件"""
    target_physical = self.virtual_to_physical(target_path)
    
    with zipfile.ZipFile(target_physical, 'w', zipfile.ZIP_DEFLATED) as zipf:
        for source_path in source_paths:
            source_physical = self.virtual_to_physical(source_path)
            source_path_obj = Path(source_physical)
            
            if source_path_obj.is_dir():
                for file_path in source_path_obj.rglob('*'):
                    if file_path.is_file():
                        arcname = str(file_path.relative_to(source_path_obj.parent))
                        zipf.write(file_path, arcname)
            else:
                zipf.write(source_physical, source_path_obj.name)
    
    return {
        'path': target_path,
        'size': Path(target_physical).stat().st_size
    }

def decompress(self, archive_path, target_path, overwrite=False):
    """解压缩文件"""
    archive_physical = self.virtual_to_physical(archive_path)
    target_physical = self.virtual_to_physical(target_path)
    
    Path(target_physical).mkdir(parents=True, exist_ok=True)
    
    with zipfile.ZipFile(archive_physical, 'r') as zipf:
        for member in zipf.namelist():
            target_file = Path(target_physical) / member
            
            if target_file.exists() and not overwrite:
                continue
            
            target_file.parent.mkdir(parents=True, exist_ok=True)
            
            with zipf.open(member) as source:
                with open(target_file, 'wb') as target:
                    target.write(source.read())
    
    return {
        'extractedPath': target_path
    }

def list_archive(self, archive_path):
    """列出压缩包内容"""
    archive_physical = self.virtual_to_physical(archive_path)
    
    files = []
    total_size = 0
    
    with zipfile.ZipFile(archive_physical, 'r') as zipf:
        for info in zipf.infolist():
            files.append({
                'name': info.filename,
                'size': info.file_size,
                'compressedSize': info.compress_size,
                'modified': info.date_time
            })
            total_size += info.file_size
    
    return {
        'path': archive_path,
        'files': files,
        'totalSize': total_size
    }
```
