# 6.2.1 randomSecurity 服务详解

## 本节导读

本节使读者能够：**① 理解 randomSecurity 服务的职责——签发和清除 JWT Token；② 掌握 Token 签发的完整流程——用户认证、权限查询、Payload 构建、签名生成；③ 理解两种 Token 类型（SystemToken 和 UserToken）的区别与使用场景。** 源码位置：`system/service/randomSecurity.php`。

---

## 一、randomSecurity 服务概述

### 1.1 服务职责

`randomSecurity.php` 是 ZerOS 的安全认证入口点，负责：

1. **用户登录认证**：验证用户名密码，签发 JWT Token
2. **Token 清除**：处理用户登出，清除客户端存储的 Token
3. **Token 刷新**（可选）：延长 Token 有效期

### 1.2 访问地址

```
POST /system/service/randomSecurity.php?action=issue
POST /system/service/randomSecurity.php?action=clear
```

## 二、用户登录与 Token 签发

### 2.1 登录请求格式

```http
POST /system/service/randomSecurity.php?action=issue
Content-Type: application/x-www-form-urlencoded

username=root&password=200714&tokenType=UserToken
```

### 2.2 登录处理流程

```php
<?php
// system/service/randomSecurity.php

header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: GET, POST, OPTIONS');

require_once __DIR__ . '/jwtVerify.php';

// 处理 OPTIONS 预检请求
if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(200);
    exit;
}

$action = $_GET['action'] ?? '';

// Token 签发
if ($action === 'issue') {
    $username = $_POST['username'] ?? '';
    $password = $_POST['password'] ?? '';
    $tokenType = $_POST['tokenType'] ?? 'UserToken';
    
    // 参数校验
    if (empty($username) || empty($password)) {
        sendResponse(false, '用户名和密码不能为空', null, 400);
    }
    
    // 验证凭据
    $userData = verifyCredentials($username, $password);
    if (!$userData) {
        sendResponse(false, '用户名或密码错误', null, 401);
    }
    
    // 构建 Token Payload
    $payload = [
        'username' => $username,
        'userId' => $userData['id'],
        'type' => $tokenType,
        'permissions' => $userData['permissions'],
        'loginTime' => time()
    ];
    
    // 生成 JWT
    $token = generateJWT($payload);
    
    sendResponse(true, '登录成功', [
        'token' => $token,
        'tokenType' => $tokenType,
        'username' => $username,
        'userId' => $userData['id']
    ]);
}

// Token 清除（登出）
if ($action === 'clear') {
    sendResponse(true, '已退出登录', null);
}
```

### 2.3 凭据验证实现

```php
function verifyCredentials($username, $password) {
    // 读取用户数据
    $sdataPath = dirname(__DIR__) . '/DISK/D/LocalSData.json';
    if (!file_exists($sdataPath)) {
        return false;
    }
    
    $sdata = json_decode(file_get_contents($sdataPath), true);
    $users = $sdata['userControl']['users'] ?? [];
    
    // 查找用户
    foreach ($users as $user) {
        if ($user['username'] === $username) {
            // 验证密码（使用 MD5 变体）
            $encryptedPassword = md5($password);
            
            // 检查密码（兼容旧版本简单哈希）
            if ($user['password'] === $encryptedPassword || 
                $user['password'] === $password) {
                return [
                    'id' => $user['id'],
                    'username' => $user['username'],
                    'permissions' => $user['permissions'] ?? []
                ];
            }
        }
    }
    
    return false;
}
```

## 三、JWT 生成实现

### 3.1 JWT 结构

JWT 由三部分组成，用 `.` 分隔：

```
xxxxx.yyyyy.zzzzz
  │      │     └─ Signature（签名）
  │      └─ Payload（负载）
  └─ Header（头部）
```

### 3.2 生成函数

```php
function generateJWT($payload) {
    $secret = getJWTSecret();
    
    // 1. 构建 Header
    $header = [
        'typ' => 'JWT',
        'alg' => 'HS256'
    ];
    
    // 2. 构建 Payload
    $payload['iat'] = time(); // 签发时间
    $payload['exp'] = time() + getTokenExpireSeconds(); // 过期时间
    
    // 3. Base64URL 编码
    $headerEncoded = base64UrlEncode(json_encode($header));
    $payloadEncoded = base64UrlEncode(json_encode($payload));
    
    // 4. 生成签名
    $signature = hash_hmac('sha256', 
        $headerEncoded . '.' . $payloadEncoded, 
        $secret
    );
    $signatureEncoded = base64UrlEncode($signature);
    
    // 5. 组合 Token
    return $headerEncoded . '.' . $payloadEncoded . '.' . $signatureEncoded;
}

function base64UrlEncode($data) {
    return rtrim(strtr(base64_encode($data), '+/', '-_'), '=');
}

function getJWTSecret() {
    // 从配置或环境变量获取签名密钥
    return getenv('JWT_SECRET') ?: 'ZerOS_Development_Secret_Key_2024';
}

function getTokenExpireSeconds() {
    // 默认 30 天
    return intval(getenv('JWT_EXPIRE_SECONDS')) ?: 30 * 24 * 3600;
}
```

### 3.3 Token Payload 示例

```json
{
    "username": "root",
    "userId": "root",
    "type": "UserToken",
    "permissions": ["KERNEL_DISK_READ", "KERNEL_DISK_WRITE"],
    "iat": 1701234567,
    "exp": 1703826567,
    "loginTime": 1701234567
}
```

## 四、两种 Token 类型

### 4.1 UserToken（用户 Token）

- **用途**：普通用户操作
- **权限**：继承自用户账户的权限
- **有效期**：默认 30 天
- **使用场景**：文件操作、应用启动、设置修改

### 4.2 SystemToken（系统 Token）

- **用途**：系统级操作
- **权限**：管理员全部权限
- **有效期**：可独立配置
- **使用场景**：
  - 系统安装/初始化
  - 用户管理
  - 敏感文件写入

### 4.3 签发时指定类型

```php
$tokenType = $_POST['tokenType'] ?? 'UserToken';

// 只有特定用户可以获取 SystemToken
if ($tokenType === 'SystemToken') {
    if (!$userIsAdmin($username)) {
        sendResponse(false, '无权限获取系统 Token', null, 403);
    }
}
```

## 六、与前端内核的协作

### 6.1 登录流程

```javascript
// kernel/core/usercontrol/userControl.js

async login(username, password) {
    const response = await fetch('/system/service/randomSecurity.php?action=issue', {
        method: 'POST',
        body: new URLSearchParams({
            username,
            password,
            tokenType: 'UserToken'
        })
    });
    
    const result = await response.json();
    
    if (result.success) {
        // 存储 Token
        await LStorage.setSystemStorage('jwtToken', result.data.token);
        await LStorage.setUserStorage('currentUser', result.data.username);
        
        return result.data;
    }
    
    throw new Error(result.message);
}
```

## 本节小结

本节详细讲解了 randomSecurity 服务的完整实现：

1. **服务职责**：签发 JWT Token、清除 Token
2. **登录流程**：验证用户名密码 → 查询用户权限 → 构建 Payload → 生成签名
3. **JWT 结构**：Header.Payload.Signature，Base64URL 编码
4. **两种 Token**：UserToken（用户级）、SystemToken（系统级）
5. **Payload 内容**：username、userId、type、permissions、iat、exp
