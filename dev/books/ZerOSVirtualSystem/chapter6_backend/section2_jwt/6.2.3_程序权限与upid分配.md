# 6.2.3 程序权限与 upid 分配

## 本节导读

本节使读者能够：**① 理解 upid（Program Unique Identifier）的概念与生成算法；② 掌握程序权限的分配、查询、与撤销流程；③ 理解权限的持久化存储机制——LocalSData.json 中的 permissionControl 结构。** 源码位置：`system/service/programPermissions.php`。

---

## 一、upid 概述

### 1.1 什么是 upid

**upid（Program Unique Identifier）** 是 ZerOS 中每个已注册程序的唯一标识符。它的作用类似于操作系统中的进程 ID，但更侧重于权限管理：

- **格式**：`{programName}_{timestamp}_{random}`
- **示例**：`filemanager_1701234567_a1b2c3`
- **生命周期**：程序启动时分配，进程退出后回收

### 1.2 upid 的作用

1. **权限绑定**：将程序名称映射到其拥有的权限集合
2. **审计追踪**：记录每个程序的操作行为
3. **权限隔离**：不同程序即使名称相同，只要 upid 不同就拥有独立权限

## 二、程序权限注册

### 2.1 注册请求

```http
POST /system/service/programPermissions.php?action=assign
Content-Type: application/json

{
    "programName": "filemanager",
    "permissions": ["KERNEL_DISK_READ", "KERNEL_DISK_WRITE", "KERNEL_DISK_DELETE"]
}
```

### 2.2 分配 upid

```php
<?php
// system/service/programPermissions.php

function assignUpid($programName, $permissions) {
    // 1. 生成唯一 ID
    $timestamp = time();
    $random = substr(md5(uniqid(rand(), true)), 0, 6);
    $upid = $programName . '_' . $timestamp . '_' . $random;
    
    // 2. 读取现有权限数据
    $sdataPath = dirname(__DIR__) . '/DISK/D/LocalSData.json';
    $sdata = json_decode(file_get_contents($sdataPath), true);
    
    // 3. 初始化权限结构
    if (!isset($sdata['permissionControl'])) {
        $sdata['permissionControl'] = [];
    }
    if (!isset($sdata['permissionControl']['programPermissions'])) {
        $sdata['permissionControl']['programPermissions'] = [];
    }
    
    // 4. 存储程序权限映射
    $sdata['permissionControl']['programPermissions'][$upid] = [
        'programName' => $programName,
        'permissions' => $permissions,
        'assignedAt' => $timestamp,
        'lastUsed' => $timestamp
    ];
    
    // 5. 写入存储
    file_put_contents($sdataPath, json_encode($sdata, JSON_PRETTY_PRINT));
    
    return [
        'upid' => $upid,
        'programName' => $programName,
        'permissions' => $permissions
    ];
}
```

### 2.3 权限等级

ZerOS 的权限分为三个等级：

| 等级 | 常量 | 说明 | 授权方式 |
|------|------|------|---------|
| 0 | NORMAL | 普通权限 | 自动授予，无需用户确认 |
| 1 | SPECIAL | 特殊权限 | 需要用户确认 |
| 2 | DANGEROUS | 危险权限 | 仅管理员可授权 |

```php
// 权限等级定义
$PERMISSION_LEVELS = [
    // 普通权限（等级 0）
    'KERNEL_DISK_READ' => 0,
    'KERNEL_DISK_WRITE' => 0,
    'KERNEL_DISK_DELETE' => 0,
    'NETWORK_ACCESS' => 0,
    
    // 特殊权限（等级 1）
    'CAMERA_ACCESS' => 1,
    'LOCATION_ACCESS' => 1,
    'SPEECH_RECOGNITION' => 1,
    
    // 危险权限（等级 2）
    'SYSTEM_STORAGE_WRITE' => 2,
    'PROCESS_MANAGE' => 2,
    'SERVER_SERVICE_MANAGE' => 2,
];

function getPermissionLevel($permission) {
    return $PERMISSION_LEVELS[$permission] ?? 0;
}
```

## 三、权限查询与校验

### 3.1 查询程序权限

```php
function getProgramPermissions($programName) {
    $sdataPath = dirname(__DIR__) . '/DISK/D/LocalSData.json';
    $sdata = json_decode(file_get_contents($sdataPath), true);
    
    $programPerms = $sdata['permissionControl']['programPermissions'] ?? [];
    
    // 查找该程序的所有 upid
    $result = [];
    foreach ($programPerms as $upid => $info) {
        if ($info['programName'] === $programName) {
            $result[$upid] = $info;
        }
    }
    
    return $result;
}
```

### 3.2 校验单个权限

```php
function hasPermission($programName, $requiredPermission) {
    $programPerms = getProgramPermissions($programName);
    
    foreach ($programPerms as $info) {
        if (in_array($requiredPermission, $info['permissions'])) {
            return true;
        }
    }
    
    return false;
}
```

### 3.3 权限校验示例

在 FSDirve 中使用：

```php
function handleReadFile() {
    $path = $_POST['path'] ?? '';
    $programName = $_POST['programName'] ?? '';
    
    // 校验权限
    if (!hasPermission($programName, 'KERNEL_DISK_READ')) {
        sendResponse(false, '无读取权限', null, 403);
    }
    
    // 继续处理...
}
```

## 四、权限回收

### 4.1 回收 upid

```php
function revokeUpid($upid) {
    $sdataPath = dirname(__DIR__) . '/DISK/D/LocalSData.json';
    $sdata = json_decode(file_get_contents($sdataPath), true);
    
    if (isset($sdata['permissionControl']['programPermissions'][$upid])) {
        unset($sdata['permissionControl']['programPermissions'][$upid]);
        file_put_contents($sdataPath, json_encode($sdata, JSON_PRETTY_PRINT));
        return true;
    }
    
    return false;
}
```

### 4.2 批量回收

```php
function revokeAllForProgram($programName) {
    $sdataPath = dirname(__DIR__) . '/DISK/D/LocalSData.json';
    $sdata = json_decode(file_get_contents($sdataPath), true);
    
    $programPerms = &$sdata['permissionControl']['programPermissions'];
    
    $removed = 0;
    foreach ($programPerms as $upid => $info) {
        if ($info['programName'] === $programName) {
            unset($programPerms[$upid]);
            $removed++;
        }
    }
    
    file_put_contents($sdataPath, json_encode($sdata, JSON_PRETTY_PRINT));
    return $removed;
}
```

## 五、LocalSData.json 中的存储结构

### 5.1 permissionControl 结构

```json
{
    "permissionControl": {
        "programPermissions": {
            "filemanager_1701234567_a1b2c3": {
                "programName": "filemanager",
                "permissions": [
                    "KERNEL_DISK_READ",
                    "KERNEL_DISK_WRITE",
                    "KERNEL_DISK_DELETE"
                ],
                "assignedAt": 1701234567,
                "lastUsed": 1701234567
            },
            "notepad_1701234568_d4e5f6": {
                "programName": "notepad",
                "permissions": [
                    "KERNEL_DISK_READ",
                    "KERNEL_DISK_WRITE"
                ],
                "assignedAt": 1701234568,
                "lastUsed": 1701235000
            }
        },
        "defaultPermissions": {
            "filemanager": ["KERNEL_DISK_READ", "KERNEL_DISK_WRITE"],
            "notepad": ["KERNEL_DISK_READ", "KERNEL_DISK_WRITE"]
        }
    }
}
```

### 5.2 权限继承

```php
function getEffectivePermissions($programName) {
    // 1. 获取程序显式权限
    $explicit = getProgramPermissions($programName);
    
    // 2. 合并默认权限
    $sdataPath = dirname(__DIR__) . '/DISK/D/LocalSData.json';
    $sdata = json_decode(file_get_contents($sdataPath), true);
    $defaultPerms = $sdata['permissionControl']['defaultPermissions'][$programName] ?? [];
    
    // 3. 返回合并结果
    return array_unique(array_merge($defaultPerms, $explicit));
}
```

## 六、与内核的协作

### 6.1 内核中的权限分配

```javascript
// kernel/process/permissionManager.js

async registerProgram(programName, permissions) {
    // 调用后端 API 分配 upid
    const response = await fetch('/system/service/programPermissions.php?action=assign', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
            programName,
            permissions
        })
    });
    
    const result = await response.json();
    return result.data.upid;
}
```

### 6.2 权限检查

```javascript
async checkPermission(permission) {
    const ProcessManager = POOL.__GET__('KERNEL_GLOBAL_POOL', 'ProcessManager');
    return await ProcessManager.callKernelAPI(
        this.pid,
        'Permission.check',
        [permission]
    );
}
```

## 本节小结

本节详细讲解了程序权限与 upid 分配机制：

2. **权限分配**：程序启动时分配 upid 并绑定权限集合
