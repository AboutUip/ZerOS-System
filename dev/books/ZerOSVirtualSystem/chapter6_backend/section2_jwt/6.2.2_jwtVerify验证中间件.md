# 6.2.2 jwtVerify 验证中间件

## 本节导读

本节使读者能够：**① 理解 jwtVerify 中间件的设计理念——作为所有后端服务的入口拦截器；② 掌握 JWT Token 验证的完整流程——签名验证、过期检查、Payload 解析；③ 理解服务级别权限校验的实现——不同服务可以要求不同的权限级别。** 源码位置：`system/service/jwtVerify.php`。

---

## 一、jwtVerify 中间件概述

### 1.1 设计理念

ZerOS 后端采用「入口统一校验」模式：每个后端服务文件（`FSDirve.php`、`CompressionDirve.php` 等）在处理业务逻辑之前，都必须引入 `jwtVerify.php`。这种设计确保：

1. **安全性一致性**：所有服务共享同一套验证逻辑，避免遗漏
2. **维护成本降低**：修改验证规则只需改一处
3. **职责分离**：验证逻辑与业务逻辑解耦

### 1.2 工作流程

```
HTTP 请求到达服务
        │
        ▼
┌──────────────────┐
│  检查白名单路径   │  ← randomSecurity、静态资源等无需验证
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  获取 Token      │  ← 从 Header 或 Query 参数
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  验证 Token      │  ← 签名、过期时间
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  服务权限校验    │  ← 可选：检查是否有权访问该服务
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  存入全局变量    │  ← 供后续业务逻辑使用
└────────┬─────────┘
         │
         ▼
    业务逻辑处理
```

## 二、中间件核心实现

### 2.1 入口函数

```php
<?php
// system/service/jwtVerify.php

function requireJWTVerify($serviceName = null) {
    // 1. 检查是否为白名单路径
    if (isWhitelistedPath()) {
        return;
    }
    
    // 2. 获取 Token
    $token = getTokenFromRequest();
    if (empty($token)) {
        sendResponse(false, '缺少认证 Token', null, 401);
    }
    
    // 3. 验证 Token
    $payload = verifyJWT($token);
    if (!$payload) {
        sendResponse(false, '无效的 Token', null, 401);
    }
    
    // 4. 服务权限校验（可选）
    if ($serviceName !== null && !checkServicePermission($payload, $serviceName)) {
        sendResponse(false, '无权限访问该服务', null, 403);
    }
    
    // 5. 将 Payload 存入全局变量
    $GLOBALS['jwt_payload'] = $payload;
    $GLOBALS['jwt_token'] = $token;
}
```

### 2.2 白名单路径

```php
function isWhitelistedPath() {
    $whitelist = [
        '/randomSecurity',      // 登录服务
        '/install-service',    // 安装服务
        '/install-extract',    // 安装提取
        '/test.php',           // 测试
    ];
    
    $requestUri = $_SERVER['REQUEST_URI'];
    
    foreach ($whitelist as $path) {
        if (strpos($requestUri, $path) !== false) {
            return true;
        }
    }
    
    return false;
}
```

### 2.3 Token 获取

```php
function getTokenFromRequest() {
    // 1. 尝试从 Header 获取
    $token = $_SERVER['HTTP_X_JWT'] ?? '';
    
    if (!empty($token)) {
        return $token;
    }
    
    // 2. 尝试从 Query 参数获取
    $token = $_GET['jwt'] ?? '';
    
    if (!empty($token)) {
        return $token;
    }
    
    // 3. 尝试从 Authorization Header 获取
    $authHeader = $_SERVER['HTTP_AUTHORIZATION'] ?? '';
    if (preg_match('/Bearer\s+(.+)/i', $authHeader, $matches)) {
        return $matches[1];
    }
    
    return '';
}
```

## 三、Token 验证实现

### 3.1 验证函数

```php
function verifyJWT($token) {
    // 1. 分割 Token
    $parts = explode('.', $token);
    if (count($parts) !== 3) {
        KernelLogger::warning('jwtVerify', 'Token 格式错误：段数不正确');
        return false;
    }
    
    list($headerEncoded, $payloadEncoded, $signatureEncoded) = $parts;
    
    // 2. 验证签名
    $expectedSignature = generateSignature($headerEncoded, $payloadEncoded);
    if (!hash_equals($expectedSignature, $signatureEncoded)) {
        KernelLogger::warning('jwtVerify', 'Token 签名验证失败');
        return false;
    }
    
    // 3. 解析 Header
    $header = json_decode(base64UrlDecode($headerEncoded), true);
    if (!$header || !isset($header['alg'])) {
        return false;
    }
    
    // 4. 解析 Payload
    $payload = json_decode(base64UrlDecode($payloadEncoded), true);
    if (!$payload) {
        return false;
    }
    
    // 5. 检查过期时间
    if (isset($payload['exp']) && $payload['exp'] < time()) {
        KernelLogger::warning('jwtVerify', 'Token 已过期');
        return false;
    }
    
    // 6. 检查签发时间（可选，防止使用过期的 Token）
    if (isset($payload['iat']) && $payload['iat'] > time()) {
        KernelLogger::warning('jwtVerify', 'Token 签发时间异常');
        return false;
    }
    
    return $payload;
}
```

### 3.2 签名生成

```php
function generateSignature($headerEncoded, $payloadEncoded) {
    $secret = getJWTSecret();
    
    $signature = hash_hmac('sha256', 
        $headerEncoded . '.' . $payloadEncoded, 
        $secret
    );
    
    return base64UrlEncode($signature);
}

function base64UrlDecode($data) {
    $remainder = strlen($data) % 4;
    if ($remainder) {
        $data .= str_repeat('=', 4 - $remainder);
    }
    return base64_decode(strtr($data, '-_', '+/'));
}
```

## 四、服务级别权限校验

### 4.1 服务权限映射

不同服务可以要求不同的权限级别：

```php
// 服务所需权限映射
$SERVICE_PERMISSIONS = [
    'FSDirve' => ['KERNEL_DISK_READ', 'KERNEL_DISK_WRITE'],
    'CompressionDirve' => ['KERNEL_DISK_READ', 'KERNEL_DISK_WRITE'],
    'DISKMANAGER' => ['SYSTEM_DISK_MANAGE'],
    'NetworkDrive' => ['NETWORK_ACCESS'],
    // 无权限要求的服务
    'ImageProxy' => [],
    'AudioProxy' => [],
];
```

### 4.2 权限校验实现

```php
function checkServicePermission($payload, $serviceName) {
    // 1. 如果服务没有权限要求，直接放行
    $required = $SERVICE_PERMISSIONS[$serviceName] ?? [];
    if (empty($required)) {
        return true;
    }
    
    // 2. 如果是 SystemToken，拥有所有权限
    if (($payload['type'] ?? '') === 'SystemToken') {
        return true;
    }
    
    // 3. 检查用户权限
    $userPermissions = $payload['permissions'] ?? [];
    
    foreach ($required as $permission) {
        if (!in_array($permission, $userPermissions)) {
            KernelLogger::warning('jwtVerify', 
                "权限不足：需要 {$permission}，用户拥有 " . implode(', ', $userPermissions));
            return false;
        }
    }
    
    return true;
}
```

### 4.3 结合 upid 的校验

对于更细粒度的控制，可以结合 upid：

```php
function checkPermissionWithUpid($requiredPermission) {
    $payload = $GLOBALS['jwt_payload'] ?? null;
    
    if (!$payload) {
        return false;
    }
    
    // 1. SystemToken 拥有所有权限
    if (($payload['type'] ?? '') === 'SystemToken') {
        return true;
    }
    
    // 2. 获取程序权限
    $programPermissions = $payload['permissions'] ?? [];
    
    // 3. 检查权限
    return in_array($requiredPermission, $programPermissions);
}
```

## 五、在服务中引入 jwtVerify

### 5.1 FSDirve.php 示例

```php
<?php
// system/service/FSDirve.php

header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');

// 1. 引入并执行 JWT 验证
require_once __DIR__ . '/jwtVerify.php';
requireJWTVerify('FSDirve');  // 传入服务名，进行服务级别权限校验

// 2. 业务逻辑
$action = $_GET['action'] ?? $_POST['action'] ?? '';

switch ($action) {
    case 'read_file':
        // 读取文件（已通过 JWT 验证）
        handleReadFile();
        break;
    // ...
}
```

### 5.2 ImageProxy.php 示例

```php
<?php
// system/service/ImageProxy.php

require_once __DIR__ . '/jwtVerify.php';
requireJWTVerify('ImageProxy');  // ImageProxy 无特殊权限要求

// 直接处理图片代理，无需额外权限
$url = $_GET['url'] ?? '';
// ...
```
