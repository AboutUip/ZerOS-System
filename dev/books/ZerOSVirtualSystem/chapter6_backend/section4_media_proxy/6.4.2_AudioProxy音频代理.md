# 6.4.2 AudioProxy 音频代理

## 本节导读

本节使读者能够：**① 理解 AudioProxy 的作用——解决浏览器加载外部音频时的跨域限制，并支持流式播放；② 掌握 Range 请求的实现——允许音频文件的部分加载，支持seek操作；③ 理解音频格式的校验与限制。** 源码位置：`system/service/audio-proxy.php`。

---

## 一、服务概述

### 1.1 问题背景

与图片类似，浏览器加载外部音频文件也会遇到跨域限制。此外，音频播放器通常需要支持：

- **流式播放**：不必等待整个文件下载完成即可播放
- **Seek（跳转）**：允许用户拖动进度条跳过到任意位置

这两个功能依赖于 HTTP **Range 请求**。

### 1.2 AudioProxy 功能

1. **跨域代理**：解决 CORS 限制
2. **Range 支持**：支持流式播放和 seek
3. **格式校验**：确保是有效的音频文件

---

## 二、Range 请求原理

### 2.1 HTTP Range 请求

客户端在请求头中指定希望获取的字节范围：

```
GET /audio.mp3 HTTP/1.1
Range: bytes=0-1048575  // 请求前 1MB
```

服务器返回 206 Partial Content 状态码，并携带指定范围的内容：

```
HTTP/1.1 206 Partial Content
Content-Type: audio/mpeg
Content-Length: 1048576
Content-Range: bytes 0-1048575/12345678

[二进制数据...]
```

### 2.2 多范围请求

```
Range: bytes=0-1048575, 1048576-2097151
```

服务器会返回 multipart/byteranges 格式。

## 三、实现代码

```php
<?php
// system/service/audio-proxy.php

$ALLOWED_TYPES = [
    'audio/mpeg',      // MP3
    'audio/wav',       // WAV
    'audio/ogg',       // OGG
    'audio/flac',      // FLAC
    'audio/aac',       // AAC
    'audio/mp4',      // M4A
    'audio/webm'       // WebM
];

function handleAudioProxy() {
    global $ALLOWED_TYPES;
    
    // 1. 获取 URL
    $url = $_GET['url'] ?? '';
    $url = urldecode($url);
    
    if (empty($url)) {
        http_response_code(400);
        exit;
    }
    
    // 2. URL 校验
    $parsedUrl = parse_url($url);
    if (($parsedUrl['scheme'] ?? '') !== 'https') {
        http_response_code(400);
        echo 'Only HTTPS URLs are allowed';
        exit;
    }
    
    // 3. 获取音频文件头信息（不下载完整文件）
    $context = stream_context_create([
        'http' => [
            'timeout' => 10,
            'method' => 'HEAD',
            'user_agent' => 'ZerOS AudioProxy/1.0'
        ]
    ]);
    
    $headers = @get_headers($url, true, $context);
    
    if (!$headers || strpos($headers[0], '200') === false) {
        http_response_code(502);
        exit;
    }
    
    // 4. 检查 Content-Type
    $contentType = $headers['Content-Type'] ?? '';
    if (is_array($contentType)) {
        $contentType = $contentType[0];
    }
    
    // 去除参数（如 audio/mpeg; charset=utf-8）
    $contentType = explode(';', $contentType)[0];
    
    if (!in_array($contentType, $ALLOWED_TYPES)) {
        http_response_code(403);
        echo 'Audio type not allowed: ' . $contentType;
        exit;
    }
    
    // 5. 获取文件大小
    $fileSize = isset($headers['Content-Length']) 
        ? intval($headers['Content-Length']) 
        : 0;
    
    // 6. 处理 Range 请求
    $rangeHeader = $_SERVER['HTTP_RANGE'] ?? '';
    
    if (!empty($rangeHeader)) {
        handleRangeRequest($url, $rangeHeader, $fileSize, $contentType);
    } else {
        // 非 Range 请求：返回完整文件
        sendFullFile($url, $fileSize, $contentType);
    }
}

function handleRangeRequest($url, $rangeHeader, $fileSize, $contentType) {
    // 解析 Range 头
    // 格式: bytes=start-end
    preg_match('/bytes=(\d*)-(\d*)/', $rangeHeader, $matches);
    
    $start = !empty($matches[1]) ? intval($matches[1]) : 0;
    $end = !empty($matches[2]) ? intval($matches[2]) : $fileSize - 1;
    
    // 校验范围
    if ($start >= $fileSize || $end >= $fileSize || $start > $end) {
        http_response_code(416); // Range Not Satisfiable
        header('Content-Range: bytes */' . $fileSize);
        exit;
    }
    
    // 获取部分内容
    $context = stream_context_create([
        'http' => [
            'timeout' => 30,
            'header' => "Range: bytes=$start-$end\r\n"
        ]
    ]);
    
    $data = @file_get_contents($url, false, $context);
    
    if ($data === false) {
        http_response_code(502);
        exit;
    }
    
    // 返回 206 Partial Content
    $length = strlen($data);
    
    http_response_code(206);
    header('Content-Type: ' . $contentType);
    header('Content-Length: ' . $length);
    header('Content-Range: bytes ' . $start . '-' . $end . '/' . $fileSize);
    header('Accept-Ranges: bytes');
    header('Cache-Control: public, max-age=86400');
    
    echo $data;
}

function sendFullFile($url, $fileSize, $contentType) {
    $context = stream_context_create([
        'http' => [
            'timeout' => 300
        ]
    ]);
    
    $data = @file_get_contents($url, false, $context);
    
    if ($data === false) {
        http_response_code(502);
        exit;
    }
    
    header('Content-Type: ' . $contentType);
    header('Content-Length: ' . strlen($data));
    header('Accept-Ranges: bytes');
    header('Cache-Control: public, max-age=86400');
    
    echo $data;
}
```

## 四、前端使用

```javascript
// 前端使用 AudioProxy
const audioUrl = 'https://example.com/music.mp3';
const proxyUrl = `/system/service/audio-proxy.php?url=${encodeURIComponent(audioUrl)}`;

const audio = new Audio(proxyUrl);
audio.play();
```
