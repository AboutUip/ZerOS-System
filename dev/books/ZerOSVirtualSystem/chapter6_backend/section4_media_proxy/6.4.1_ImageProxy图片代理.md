# 6.4.1 ImageProxy 图片代理

## 本节导读

本节使读者能够：**① 理解 ImageProxy 的作用——解决浏览器加载外部图片时的跨域限制；② 掌握图片代理的实现原理——后端获取图片后转发给前端；③ 理解安全限制——仅允许 HTTPS，仅允许特定图片格式。** 源码位置：`system/service/ImageProxy.php`。

---

## 一、服务概述

### 1.1 问题背景

浏览器出于安全考虑，禁止从不同域名加载图片（除非目标服务器设置了 CORS 头）。当 ZerOS 程序需要显示来自互联网的图片时，会遇到跨域问题：

```javascript
// 浏览器直接加载外部图片会被阻止
<img src="https://external-site.com/image.jpg">
```

### 1.2 解决方案

ImageProxy 作为代理服务器：
1. 前端请求 ImageProxy，传入目标图片 URL
2. ImageProxy 验证并获取图片
3. ImageProxy 将图片转发给前端（此时域名相同，无跨域问题）

---

## 二、接口规范

### 2.1 请求格式

```
GET /system/service/ImageProxy.php?url=<encoded_url>
```

或

```
POST /system/service/ImageProxy.php
Content-Type: application/json

{
    "url": "https://example.com/image.jpg"
}
```

### 2.2 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| url | string | 是 | 要代理的图片 URL（URL 编码） |

## 三、实现代码

```php
<?php
// system/service/ImageProxy.php

// 允许的图片格式
$ALLOWED_TYPES = [
    'image/jpeg',
    'image/png',
    'image/gif',
    'image/webp',
    'image/svg+xml'
];

// 允许的来源域名（可选）
$ALLOWED_DOMAINS = []; // 空数组表示允许所有

// 不需要 JWT 验证（图片代理是公开的）
// require_once __DIR__ . '/jwtVerify.php';
// requireJWTVerify('ImageProxy');

function handleImageProxy() {
    global $ALLOWED_TYPES, $ALLOWED_DOMAINS;
    
    // 1. 获取 URL
    $url = $_GET['url'] ?? $_POST['url'] ?? '';
    $url = urldecode($url);
    
    if (empty($url)) {
        http_response_code(400);
        echo 'Missing url parameter';
        exit;
    }
    
    // 2. URL 校验
    if (!filter_var($url, FILTER_VALIDATE_URL)) {
        http_response_code(400);
        echo 'Invalid URL';
        exit;
    }
    
    // 3. 协议校验（只允许 HTTPS）
    $parsedUrl = parse_url($url);
    if (($parsedUrl['scheme'] ?? '') !== 'https') {
        http_response_code(400);
        echo 'Only HTTPS URLs are allowed';
        exit;
    }
    
    // 4. 域名校验（如果配置了白名单）
    if (!empty($ALLOWED_DOMAINS)) {
        $host = $parsedUrl['host'] ?? '';
        if (!in_array($host, $ALLOWED_DOMAINS)) {
            http_response_code(403);
            echo 'Domain not allowed';
            exit;
        }
    }
    
    // 5. 获取图片
    $context = stream_context_create([
        'http' => [
            'timeout' => 10,
            'follow_location' => 1,
            'max_redirects' => 5,
            'user_agent' => 'ZerOS ImageProxy/1.0'
        ],
        'ssl' => [
            'verify_peer' => true,
            'verify_peer_name' => true
        ]
    ]);
    
    $imageData = @file_get_contents($url, false, $context);
    
    if ($imageData === false) {
        http_response_code(502);
        echo 'Failed to fetch image';
        exit;
    }
    
    // 6. MIME 类型校验
    $finfo = new finfo(FILEINFO_MIME_TYPE);
    $mimeType = $finfo->buffer($imageData);
    
    if (!in_array($mimeType, $ALLOWED_TYPES)) {
        http_response_code(403);
        echo 'Image type not allowed: ' . $mimeType;
        exit;
    }
    
    // 7. 返回图片
    header('Content-Type: ' . $mimeType);
    header('Content-Length: ' . strlen($imageData));
    header('Cache-Control: public, max-age=86400'); // 缓存 1 天
    
    echo $imageData;
}
```

## 四、与前端内核的协作

### 4.1 使用方式

```javascript
// 前端使用代理服务
const imageUrl = 'https://external-site.com/image.jpg';
const proxyUrl = `/system/service/ImageProxy.php?url=${encodeURIComponent(imageUrl)}`;

document.getElementById('myImage').src = proxyUrl;
```

### 4.2 NetworkManager 封装

```javascript
// kernel/drive/networkManager.js

getImageProxyUrl(url) {
    return `/system/service/ImageProxy.php?url=${encodeURIComponent(url)}`;
}
```

## 五、安全考虑

1. **HTTPS 强制**：只允许代理 HTTPS 图片，防止中间人攻击
2. **类型校验**：检查 MIME 类型，防止伪装成图片的可执行文件
3. **域名白名单**：可配置允许的域名列表
4. **缓存**：设置适当的缓存头，减少重复请求

本节讲解了 ImageProxy 图片代理的实现：

2. **方案**：后端代理获取图片后转发给前端
3. **安全**：HTTPS 强制、MIME 类型校验、可选域名白名单
