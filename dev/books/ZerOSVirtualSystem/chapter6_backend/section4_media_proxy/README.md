# 第6.4节：媒体代理服务

## 本节导读

媒体代理服务用于解决浏览器跨域访问媒体资源的问题。本节详细讲解 ImageProxy、AudioProxy、VideoProxy 三个服务的实现原理与使用方法。

## 本节小节

- [6.4.1 ImageProxy 图片代理](6.4.1_ImageProxy图片代理.md)
- [6.4.2 AudioProxy 音频代理](6.4.2_AudioProxy音频代理.md)
- [6.4.3 VideoProxy 视频代理](6.4.3_VideoProxy视频代理.md)

## 学习目标

完成本节学习后，读者应能够：
1. 理解媒体代理服务的作用——解决 CORS 跨域问题
2. 掌握 ImageProxy、AudioProxy、VideoProxy 的实现细节
3. 能够根据需要扩展其他代理服务
