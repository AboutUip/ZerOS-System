# 6.4.3 VideoProxy 视频代理

## 本节导读

本节使读者能够：**① 理解 VideoProxy 的作用——解决浏览器加载外部视频时的跨域限制，并支持流式播放和 Range 请求；② 掌握视频代理与音频代理的异同——都需要 Range 支持，但视频文件更大需要更优化的处理；③ 理解视频格式的校验与限制。** 源码位置：`system/service/video-proxy.php`。

---

## 一、服务概述

### 1.1 与 AudioProxy 的异同

VideoProxy 与 AudioProxy 非常相似，都需要解决：
- 跨域加载问题
- 流式播放支持
- Range 请求处理

主要差异在于：
- 视频文件通常更大（几十 MB 到几 GB）
- 需要支持更多视频格式
- 可能需要处理更复杂的请求模式

### 1.2 VideoProxy 功能

1. **跨域代理**：解决 CORS 限制
2. **Range 支持**：流式播放、seek、拖动进度条
3. **格式校验**：确保是有效的视频文件

## 三、实现代码

```php
<?php
// system/service/video-proxy.php

$ALLOWED_TYPES = [
    'video/mp4',
    'video/webm',
    'video/ogg',
    'video/quicktime',
    'video/x-msvideo',
    'video/x-matroska',
    'video/x-flv',
];

function handleVideoProxy() {
    global $ALLOWED_TYPES;
    
    $url = $_GET['url'] ?? '';
    $url = urldecode($url);
    
    if (empty($url)) {
        http_response_code(400);
        exit;
    }
    
    // URL 校验
    $parsedUrl = parse_url($url);
    if (($parsedUrl['scheme'] ?? '') !== 'https') {
        http_response_code(400);
        exit;
    }
    
    // 获取文件信息
    $headers = getHeaders($url);
    if (!$headers) {
        http_response_code(502);
        exit;
    }
    
    $contentType = getContentType($headers);
    if (!in_array($contentType, $ALLOWED_TYPES)) {
        http_response_code(403);
        exit;
    }
    
    $fileSize = getFileSize($headers);
    
    // Range 请求处理
    $rangeHeader = $_SERVER['HTTP_RANGE'] ?? '';
    
    if (!empty($rangeHeader)) {
        handleRangeRequest($url, $rangeHeader, $fileSize, $contentType);
    } else {
        sendFullFile($url, $fileSize, $contentType);
    }
}

function getHeaders($url) {
    $context = stream_context_create([
        'http' => [
            'timeout' => 10,
            'method' => 'HEAD',
            'user_agent' => 'ZerOS VideoProxy/1.0'
        ]
    ]);
    
    $headers = @get_headers($url, true, $context);
    
    if (!$headers || strpos($headers[0], '200') === false) {
        return null;
    }
    
    return $headers;
}

function getContentType($headers) {
    $contentType = $headers['Content-Type'] ?? '';
    if (is_array($contentType)) {
        $contentType = $contentType[0];
    }
    return explode(';', $contentType)[0];
}

function getFileSize($headers) {
    if (isset($headers['Content-Length'])) {
        return intval($headers['Content-Length']);
    }
    return 0;
}

function handleRangeRequest($url, $rangeHeader, $fileSize, $contentType) {
    preg_match('/bytes=(\d*)-(\d*)/', $rangeHeader, $matches);
    
    $start = !empty($matches[1]) ? intval($matches[1]) : 0;
    $end = !empty($matches[2]) ? intval($matches[2]) : $fileSize - 1;
    
    if ($start >= $fileSize || $end >= $fileSize || $start > $end) {
        http_response_code(416);
        header('Content-Range: bytes */' . $fileSize);
        exit;
    }
    
    // 大文件使用流式传输
    $chunkSize = 8 * 1024 * 1024; // 8MB 块
    $end = min($end, $start + $chunkSize - 1);
    
    $context = stream_context_create([
        'http' => [
            'timeout' => 60,
            'header' => "Range: bytes=$start-$end\r\n"
        ]
    ]);
    
    $data = @file_get_contents($url, false, $context);
    
    if ($data === false) {
        http_response_code(502);
        exit;
    }
    
    $length = strlen($data);
    
    http_response_code(206);
    header('Content-Type: ' . $contentType);
    header('Content-Length: ' . $length);
    header('Content-Range: bytes ' . $start . '-' . $end . '/' . $fileSize);
    header('Accept-Ranges: bytes');
    header('Cache-Control: public, max-age=86400');
    
    echo $data;
}

function sendFullFile($url, $fileSize, $contentType) {
    // 大文件不使用此方式，直接重定向或流式处理
    // 这里简化处理
    header('Content-Type: ' . $contentType);
    header('Accept-Ranges: bytes');
    header('Location: ' . $url); // 重定向到源文件
    http_response_code(302);
}
```
