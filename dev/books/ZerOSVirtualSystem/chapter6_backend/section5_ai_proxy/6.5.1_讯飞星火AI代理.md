# 6.5.1 讯飞星火 AI 代理

## 本节导读

本节使读者能够：**① 理解讯飞星火 AI 代理的作用——将前端请求转发至讯飞星火 API，绕过 CORS 并隐藏 API Key；② 掌握代理的工作流程——接收请求、提取鉴权信息、转发请求、返回响应；③ 理解讯飞星火 API 的请求格式和鉴权方式。** 源码位置：`system/service/spark-ai-proxy.php`。

---

## 一、服务概述

### 1.1 问题背景

讯飞星火等 AI 服务的 API 不支持浏览器直接调用（跨域限制），且 API Key 不应暴露在前端代码中。AI 代理服务解决这两个问题：

1. **CORS 绕过**：后端转发请求，绕过浏览器跨域限制
2. **API Key 隐藏**：鉴权信息在服务端管理，不暴露给前端

### 1.2 讯飞星火 API 简介

讯飞星火是科大讯飞的大语言模型服务，提供 chat/completions 接口。

---

## 二、接口规范

### 2.1 请求格式

```
POST /system/service/spark-ai-proxy.php
Content-Type: application/json

{
    "_auth": {
        "appId": "讯飞应用 ID",
        "apiPassword": "讯飞 API 密钥"
    },
    "model": "spark-v3.5",
    "messages": [
        {"role": "system", "content": "你是一个助手"},
        {"role": "user", "content": "你好"}
    ],
    "temperature": 0.7
}
```

### 2.2 _auth 说明

`_auth` 对象包含讯飞 API 的鉴权信息，会在代理时被剥离并转发到讯飞请求头：

| 字段 | 说明 |
|------|------|
| appId | 讯飞应用 ID |
| apiPassword | 讯飞 API 密钥 |

## 三、实现代码

```php
<?php
// system/service/spark-ai-proxy.php

header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: POST, OPTIONS');
header('Access-Control-Allow-Headers: Content-Type');

// 处理 OPTIONS 预检请求
if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(200);
    exit;
}

// 目标 API 地址
define('SPARK_API_URL', 'https://spark-api-open.xf-yun.com/x2/chat/completions');

function handleAIProxy() {
    // 1. 获取请求体
    $input = file_get_contents('php://input');
    $data = json_decode($input, true);
    
    if (!$data) {
        sendResponse(false, '无效的请求体', null, 400);
    }
    
    // 2. 提取鉴权信息
    $auth = $data['_auth'] ?? [];
    $appId = $auth['appId'] ?? '';
    $apiPassword = $auth['apiPassword'] ?? '';
    
    if (empty($appId) || empty($apiPassword)) {
        sendResponse(false, '缺少鉴权信息', null, 401);
    }
    
    // 3. 移除 _auth，构建转发请求体
    unset($data['_auth']);
    
    // 4. 设置请求头
    $headers = [
        'Content-Type: application/json',
        'X-App-Id: ' . $appId,
        'Authorization: Bearer ' . $apiPassword
    ];
    
    // 5. 发送请求到讯飞
    $response = sendRequest(SPARK_API_URL, $data, $headers);
    
    // 6. 返回响应
    if ($response['success']) {
        sendResponse(true, '请求成功', $response['data']);
    } else {
        sendResponse(false, $response['error'], null, $response['code'] ?? 500);
    }
}

function sendRequest($url, $data, $headers) {
    $ch = curl_init();
    
    curl_setopt($ch, CURLOPT_URL, $url);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
    curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_TIMEOUT, 120);
    
    $response = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $error = curl_error($ch);
    
    curl_close($ch);
    
    if ($error) {
        return [
            'success' => false,
            'error' => $error,
            'code' => 502
        ];
    }
    
    return [
        'success' => true,
        'data' => json_decode($response, true)
    ];
}

function sendResponse($success, $message, $data, $code = 200) {
    http_response_code($code);
    
    $response = [
        'success' => $success,
        'message' => $message
    ];
    
    if ($data !== null) {
        $response['data'] = $data;
    }
    
    echo json_encode($response, JSON_UNESCAPED_UNICODE);
    exit;
}

// 执行处理
handleAIProxy();
```

## 四、安全考虑

1. **鉴权信息不存储**：代理不存储 API Key，每次请求由前端传入
2. **HTTPS 强制**：只允许转发到 HTTPS 端点
3. **请求日志**：建议记录请求日志以便审计
