# 6.5.2 通义千问 AI 代理

## 本节导读

本节使读者能够：**① 理解通义千问 AI 代理的作用——将前端请求转发至阿里云 DashScope API；② 掌握通义千问与讯飞星火代理的异同——鉴权方式不同（API Key vs Bearer Token）；③ 理解 OpenAI 兼容格式的使用。** 源码位置：`system/service/dashscope-ai-proxy.php`。

---

## 一、服务概述

### 1.1 通义千问 API

通义千问是阿里云推出的大语言模型，通过 DashScope 服务提供。特点：
- 与 OpenAI ChatGPT 接口格式兼容
- 使用 API Key 进行鉴权
- 支持流式响应（SSE）

### 1.2 代理作用

与讯飞星火代理类似：
1. 绕过浏览器 CORS 限制
2. 隐藏 API Key

## 三、实现代码

```php
<?php
// system/service/dashscope-ai-proxy.php

header('Content-Type: application/json; charset=utf-8');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: POST, OPTIONS');
header('Access-Control-Allow-Headers: Content-Type');

// 处理 OPTIONS 预检请求
if ($_SERVER['REQUEST_METHOD'] === 'OPTIONS') {
    http_response_code(200);
    exit;
}

// 目标 API 地址
define('DASHSCOPE_API_URL', 'https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions');

function handleAIProxy() {
    // 1. 获取请求体
    $input = file_get_contents('php://input');
    $data = json_decode($input, true);
    
    if (!$data) {
        sendResponse(false, '无效的请求体', null, 400);
    }
    
    // 2. 提取鉴权信息
    $auth = $data['_auth'] ?? [];
    $apiKey = $auth['apiKey'] ?? '';
    
    if (empty($apiKey)) {
        sendResponse(false, '缺少 API Key', null, 401);
    }
    
    // 3. 移除 _auth
    unset($data['_auth']);
    
    // 4. 判断是否流式响应
    $stream = $data['stream'] ?? false;
    
    // 5. 设置请求头
    $headers = [
        'Content-Type: application/json',
        'Authorization: Bearer ' . $apiKey,
        'X-DashScope-Async: ' . ($stream ? 'disable' : 'enable')
    ];
    
    // 6. 发送请求
    if ($stream) {
        handleStreamRequest($data, $headers);
    } else {
        handleNormalRequest($data, $headers);
    }
}

function handleNormalRequest($data, $headers) {
    $response = sendRequest(DASHSCOPE_API_URL, $data, $headers);
    
    if ($response['success']) {
        sendResponse(true, '请求成功', $response['data']);
    } else {
        sendResponse(false, $response['error'], null, $response['code'] ?? 500);
    }
}

function handleStreamRequest($data, $headers) {
    // 流式响应处理
    $headers[] = 'Accept: text/event-stream';
    $headers[] = 'Cache-Control: no-cache';
    
    $ch = curl_init();
    
    curl_setopt($ch, CURLOPT_URL, DASHSCOPE_API_URL);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
    curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, false);
    curl_setopt($ch, CURLOPT_TIMEOUT, 120);
    
    // 设置流式回调
    curl_setopt($ch, CURLOPT_WRITEFUNCTION, function($ch, $data) {
        echo $data;
        flush();
        return strlen($data);
    });
    
    curl_exec($ch);
    
    $error = curl_error($ch);
    if ($error) {
        error_log('DashScope Stream Error: ' . $error);
    }
    
    curl_close($ch);
}

function sendRequest($url, $data, $headers) {
    $ch = curl_init();
    
    curl_setopt($ch, CURLOPT_URL, $url);
    curl_setopt($ch, CURLOPT_POST, true);
    curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode($data));
    curl_setopt($ch, CURLOPT_HTTPHEADER, $headers);
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    curl_setopt($ch, CURLOPT_TIMEOUT, 120);
    
    $response = curl_exec($ch);
    $httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    $error = curl_error($ch);
    
    curl_close($ch);
    
    if ($error) {
        return [
            'success' => false,
            'error' => $error,
            'code' => 502
        ];
    }
    
    return [
        'success' => true,
        'data' => json_decode($response, true)
    ];
}

function sendResponse($success, $message, $data, $code = 200) {
    http_response_code($code);
    
    $response = [
        'success' => $success,
        'message' => $message
    ];
    
    if ($data !== null) {
        $response['data'] = $data;
    }
    
    echo json_encode($response, JSON_UNESCAPED_UNICODE);
    exit;
}

// 执行处理
handleAIProxy();
```

## 四、与讯飞星火代理的对比

| 特性 | 讯飞星火 | 通义千问 |
|------|---------|---------|
| 目标 API | spark-api-open.xf-yun.com | dashscope.aliyuncs.com |
| 鉴权方式 | X-App-Id + Bearer | Bearer Token |
| 流式支持 | 不支持 | 支持 |
| 兼容格式 | 讯飞格式 | OpenAI 兼容格式 |

---

## 本节小结

本节讲解了通义千问 AI 代理的实现：

1. **鉴权方式**：使用 Bearer Token（与 OpenAI 兼容）
2. **流式响应**：支持 Server-Sent Events（SSE）
3. **与讯飞对比**：鉴权方式不同，都提供 AI 请求代理服务
