# 第6.5节：AI 代理服务

## 本节导读

AI 代理服务用于将前端 AI 请求转发至第三方 API，绕过浏览器 CORS 限制。本节详细讲解讯飞星火和通义千问两个 AI 代理的实现。

## 本节小节

- [6.5.1 讯飞星火 AI 代理](6.5.1_讯飞星火AI代理.md)
- [6.5.2 通义千问 AI 代理](6.5.2_通义千问AI代理.md)

## 学习目标

完成本节学习后，读者应能够：
1. 理解 AI 代理服务的作用——转发 AI 请求，隐藏 API Key
2. 掌握讯飞星火和通义千问的 API 调用方式
3. 能够扩展支持其他 AI 提供商
