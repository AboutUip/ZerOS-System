## 一、读取文件操作 (read_file)

### 1.1 请求格式

```http
POST /system/service/FSDirve.php
Content-Type: application/json
X-JWT: <token>

{
    "action": "read_file",
    "path": "D:/folder/file.txt",
    "options": {
        "encoding": "utf-8"
    }
}
```

### 1.2 实现逻辑

```php
function handleReadFile() {
    // 1. 获取并校验参数
    $path = $_POST['path'] ?? $_GET['path'] ?? '';
    if (empty($path)) {
        sendResponse(false, '缺少文件路径', null, 400);
    }
    
    // 2. 路径规范化与安全校验
    if (!validatePath($path)) {
        sendResponse(false, '无效的路径', null, 400);
    }
    
    // 3. 获取 upid 并检查读权限
    $upid = getUpid();
    if (!checkPermission($upid, 'KERNEL_DISK_READ')) {
        sendResponse(false, '无读取权限', null, 403);
    }
    
    // 4. 执行文件读取
    $physicalPath = virtualToPhysical($path);
    $options = json_decode($_POST['options'] ?? '{}', true);
    $encoding = $options['encoding'] ?? 'utf-8';
    
    if (!file_exists($physicalPath)) {
        sendResponse(false, '文件不存在', null, 404);
    }
    
    // 5. 根据编码读取内容
    $content = file_get_contents($physicalPath);
    if ($encoding === 'base64') {
        $content = base64_encode($content);
    }
    
    // 6. 返回成功响应
    sendResponse(true, '读取成功', [
        'path' => $path,
        'content' => $content,
        'size' => filesize($physicalPath),
        'modified' => filemtime($physicalPath)
    ]);
}
```

### 1.3 关键细节

- **编码处理**：支持 `utf-8`（默认）和 `base64` 两种编码返回
- **大文件处理**：超过一定大小的文件应使用流式读取（`fread`）避免内存溢出
- **权限检查**：读取操作需要 `KERNEL_DISK_READ` 权限

## 二、写入文件操作 (write_file)

### 2.1 请求格式

```http
POST /system/service/FSDirve.php
Content-Type: application/json
X-JWT: <token>

{
    "action": "write_file",
    "path": "D:/folder/file.txt",
    "content": "文件内容",
    "options": {
        "encoding": "utf-8",
        "createDirs": true
    }
}
```

### 2.2 实现逻辑

```php
function handleWriteFile() {
    // 1. 参数获取
    $path = $_POST['path'] ?? '';
    $content = $_POST['content'] ?? '';
    $options = json_decode($_POST['options'] ?? '{}', true);
    
    if (empty($path)) {
        sendResponse(false, '缺少文件路径', null, 400);
    }
    
    // 2. 路径安全校验
    if (!validatePath($path)) {
        sendResponse(false, '无效的路径', null, 400);
    }
    
    // 3. 权限检查（写入需要 KERNEL_DISK_WRITE）
    $upid = getUpid();
    if (!checkPermission($upid, 'KERNEL_DISK_WRITE')) {
        sendResponse(false, '无写入权限', null, 403);
    }
    
    // 4. 敏感文件额外检查
    if (isSensitiveFile($path)) {
        if (!checkSensitiveFileWritePermission($upid, $path)) {
            sendResponse(false, '禁止写入敏感文件', null, 403);
        }
    }
    
    // 5. 自动创建父目录
    $physicalPath = virtualToPhysical($path);
    $dir = dirname($physicalPath);
    if ($options['createDirs'] ?? true) {
        if (!is_dir($dir)) {
            mkdir($dir, 0755, true);
        }
    }
    
    // 6. 写入文件（原子操作：先写临时文件再重命名）
    $tempFile = $physicalPath . '.tmp';
    $writeResult = file_put_contents($tempFile, $content);
    
    if ($writeResult === false) {
        sendResponse(false, '写入失败', null, 500);
    }
    
    // 7. 原子替换
    rename($tempFile, $physicalPath);
    
    sendResponse(true, '写入成功', [
        'path' => $path,
        'bytesWritten' => $writeResult
    ]);
}
```

### 2.3 关键细节

- **原子写入**：使用临时文件 + rename 保证写入的原子性，避免意外中断导致文件损坏
- **敏感文件检查**：对于 `LocalSData.json`、`DiskData.json` 等系统文件，需要额外权限检查
- **自动建目录**：`createDirs` 选项默认为 true，便于应用直接写入深层路径

```php
function handleCreateDir() {
    $path = $_POST['path'] ?? '';
    
    // 路径校验与权限检查（同上）
```

### 3.2 列出目录 (list_dir)

```php
function handleListDir() {
    $path = $_POST['path'] ?? '';
    
    // 路径校验与权限检查
    // ...
    
    $physicalPath = virtualToPhysical($path);
    
    if (!is_dir($physicalPath)) {
        sendResponse(false, '目录不存在', null, 404);
    }
    
    // 遍历目录
    $items = [];
    $files = scandir($physicalPath);
    
    foreach ($files as $file) {
        if ($file === '.' || $file === '..') continue;
        
        $filePath = $physicalPath . '/' . $file;
        $stat = stat($filePath);
        
        $items[] = [
            'name' => $file,
            'isDirectory' => is_dir($filePath),
            'size' => $stat['size'],
            'modified' => $stat['mtime'],
            'created' => $stat['ctime']
        ];
    }
    
    sendResponse(true, '查询成功', [
        'path' => $path,
        'items' => $items
    ]);
}
```

## 四、删除操作 (delete_file, delete_dir)

### 4.1 删除文件

```php
function handleDeleteFile() {
    $path = $_POST['path'] ?? '';
    
    // 路径校验
    // 权限检查（KERNEL_DISK_DELETE）
    
    $physicalPath = virtualToPhysical($path);
    
    if (!file_exists($physicalPath)) {
        sendResponse(false, '文件不存在', null, 404);
    }
    
    if (!unlink($physicalPath)) {
        sendResponse(false, '删除失败', null, 500);
    }
    
    sendResponse(true, '删除成功', ['path' => $path]);
}
```

### 4.2 删除目录

```php
function handleDeleteDir() {
    $path = $_POST['path'] ?? '';
    
    $physicalPath = virtualToPhysical($path);
    
    if (!is_dir($physicalPath)) {
        sendResponse(false, '目录不存在', null, 404);
    }
    
    // 检查目录是否为空
    $files = scandir($physicalPath);
    if (count($files) > 2) {
        sendResponse(false, '目录非空，无法删除', null, 400);
    }
    
    if (!rmdir($physicalPath)) {
        sendResponse(false, '删除失败', null, 500);
    }
    
    sendResponse(true, '删除成功', ['path' => $path]);
}
```

## 五、移动与复制操作 (move, copy)

### 5.1 移动操作

```php
function handleMove() {
    $source = $_POST['source'] ?? '';
    $target = $_POST['target'] ?? '';
    
    // 路径校验与权限检查
    // ...
    
    $sourcePhysical = virtualToPhysical($source);
    $targetPhysical = virtualToPhysical($target);
    
    // 目标父目录必须存在
    $targetDir = dirname($targetPhysical);
    if (!is_dir($targetDir)) {
        sendResponse(false, '目标目录不存在', null, 400);
    }
    
    if (!rename($sourcePhysical, $targetPhysical)) {
        sendResponse(false, '移动失败', null, 500);
    }
    
    sendResponse(true, '移动成功', [
        'source' => $source,
        'target' => $target
    ]);
}
```

### 5.2 复制操作

```php
function handleCopy() {
    $source = $_POST['source'] ?? '';
    $target = $_POST['target'] ?? '';
    
    $sourcePhysical = virtualToPhysical($source);
    $targetPhysical = virtualToPhysical($target);
    
    if (is_dir($sourcePhysical)) {
        // 目录复制：递归复制
        if (!recurseCopy($sourcePhysical, $targetPhysical)) {
            sendResponse(false, '复制失败', null, 500);
        }
    } else {
        // 文件复制
        if (!copy($sourcePhysical, $targetPhysical)) {
            sendResponse(false, '复制失败', null, 500);
        }
    }
    
    sendResponse(true, '复制成功', [
        'source' => $source,
        'target' => $target
    ]);
}

function recurseCopy($src, $dst) {
    $dir = opendir($src);
    @mkdir($dst);
    while (false !== ($file = readdir($dir))) {
        if ($file !== '.' && $file !== '..') {
            $srcFile = $src . '/' . $file;
            $dstFile = $dst . '/' . $file;
            if (is_dir($srcFile)) {
                recurseCopy($srcFile, $dstFile);
            } else {
                copy($srcFile, $dstFile);
            }
        }
    }
    closedir($dir);
    return true;
}
```

## 六、获取文件信息 (get_info)

```php
function handleGetInfo() {
    $path = $_POST['path'] ?? '';

    if (!file_exists($physicalPath)) {
```

## 七、响应封装 (sendResponse)

所有操作使用统一的响应格式：

```php
function sendResponse($success, $message, $data = null, $code = 200) {
    http_response_code($code);
    
    $response = [
        'success' => $success,
        'message' => $message,
        'timestamp' => date('Y-m-d H:i:s')
    ];
    
    if ($data !== null) {
        $response['data'] = $data;
    }
    
    echo json_encode($response, JSON_UNESCAPED_UNICODE);
    exit;
}
```

**响应示例**：
```json
{
    "success": true,
    "message": "读取成功",
    "timestamp": "2026-03-16 15:30:00",
    "data": {
        "path": "D:/folder/file.txt",
        "content": "文件内容",
        "size": 1024,
        "modified": 1701234567
    }
}
```

## 本节小结

本节详细讲解了 FSDirve 各类文件操作的具体实现：

1. **读取文件**：参数校验 → 权限检查 → 编码处理 → 返回内容
2. **写入文件**：原子写入（临时文件 + rename）→ 敏感文件额外检查
3. **目录操作**：创建目录、列出目录、删除目录（非空检查）
4. **删除操作**：文件和目录的删除逻辑
5. **移动/复制**：rename 和 copy 函数的封装，目录递归复制
6. **响应格式**：统一的 JSON 封装，success/message/data/timestamp 结构
