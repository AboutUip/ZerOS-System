# 6.1 文件系统驱动 FSDirve

## 本节导读

FSDirve 是 ZerOS 后端的核心文件系统服务，负责处理前端内核的所有文件操作请求。本节详细讲解其职责、架构、核心操作实现、以及 JWT 鉴权机制。

## 学习目标

完成本节学习后，读者应能够：
1. 理解 FSDirve 在 ZerOS 前后端架构中的位置
2. 掌握文件读取、写入、删除、移动、复制等操作的完整实现
3. 理解 JWT Token 生成、校验、与 upid 权限分配的完整流程
