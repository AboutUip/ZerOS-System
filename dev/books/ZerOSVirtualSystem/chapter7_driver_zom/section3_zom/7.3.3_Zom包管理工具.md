# 7.3.3 Zom 包管理工具

## 本节导读

本节使读者能够：**① 理解 Zom 包管理工具的功能——打包、解包、查看信息；② 掌握命令行工具的使用方法；③ 理解包管理器的 API 接口。**

---

## 一、命令行工具

### 1.1 常用命令

```bash
# 打包应用
zompkg pack ./myapp -o myapp.zom

# 解包应用
zompkg unpack myapp.zom -o ./output

# 查看包信息
zompkg info myapp.zom

# 列出包内容
zompkg list myapp.zom
```

---

## 二、API 接口

### 2.1 JavaScript API

```javascript
// 打包
await ZomPackage.pack(sourceDir, outputPath, options);

// 解包
await ZomPackage.unpack(zomPath, targetDir);

// 获取信息
const info = await ZomPackage.getInfo(zomPath);

// 列出内容
const files = await ZomPackage.list(zomPath);
```

---

## 本节小结

1. **命令行工具**：zompkg 命令
2. **打包/解包**：pack/unpack 命令
3. **信息查看**：info/list 命令
