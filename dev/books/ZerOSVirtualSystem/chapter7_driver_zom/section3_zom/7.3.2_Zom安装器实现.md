# 7.3.2 Zom 安装器实现

## 本节导读

本节使读者能够：**① 理解 Zom 安装器的工作流程——解压、验证、安装、注册；② 掌握安装过程中的关键步骤——权限请求、冲突检测、资源复制。**

## 一、安装流程

```
用户选择 Zom 文件
      │
      ▼
打开 Zom 包读取 manifest
      │
      ▼
检查兼容性和权限
      │
      ▼
显示安装确认对话框
      │
      ▼
解压到安装目录
      │
      ▼
注册到应用列表
      │
      ▼
安装完成
```

---

## 二、安装器实现

### 2.1 核心代码

```javascript
async install(zomPath, targetDir) {
    // 1. 读取 Zom 包
    const zip = await this._openZip(zomPath);
    const manifest = await this._readManifest(zip);
    
    // 2. 检查兼容性
    if (!this._checkCompatibility(manifest)) {
        throw new Error('应用与系统不兼容');
    }
    
    // 3. 检查是否已安装
    if (await this._isInstalled(manifest.name)) {
        throw new Error('应用已安装');
    }
    
    // 4. 解压到目标目录
    await zip.extract(targetDir);
    
    // 5. 注册应用
    await ApplicationAssetManager.register(manifest, targetDir);
    
    return { success: true, message: '安装成功' };
}
```
