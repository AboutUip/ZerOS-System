## 本节导读

本节使读者能够：**① 理解 Zom 格式——基于 ZIP 的应用程序封装格式；② 掌握 Zom 包的结构——元数据 + 程序文件；③ 理解打包工具的使用。**

---

## 一、Zom 格式

### 1.1 格式定义

Zom 是 ZerOS 应用程序的封装格式，本质是 ZIP 压缩包：

```
app.zom
├── manifest.json    # 应用元数据
├── main.js         # 入口脚本
├── assets/         # 资源文件
│   ├── icon.png
│   └── ...
└── ...
```

### 1.2 manifest.json

```json
{
    "name": "filemanager",
    "displayName": "文件管理器",
    "version": "1.0.0",
    "author": "ZerOS Team",
    "description": "ZerOS 文件管理器",
    "main": "main.js",
    "icon": "assets/icon.png",
    "permissions": [
        "KERNEL_DISK_READ",
        "KERNEL_DISK_WRITE"
    ],
    "window": {
        "width": 800,
        "height": 600,
        "resizable": true
    }
}
```

---

## 二、打包工具

### 2.1 命令行工具

```bash
# 打包
node zompkg.js pack ./myapp -o myapp.zom

# 解包
node zompkg.js unpack ./myapp.zom -o ./output

# 查看信息
node zompkg.js info ./myapp.zom
```
