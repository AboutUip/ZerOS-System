# 7.2.2 ServerExpansion 服务扩展

## 本节导读

本节使读者能够：**① 理解 ServerExpansion 的职责——管理和启动 D/server 下的系统服务；② 掌握服务模块的格式要求——必须提供五个生命周期方法；③ 理解服务的启动流程——__init__ → __start__。** 源码位置：`system/expansion/serverExpansion.js`。

---

## 一、服务扩展概述

### 1.1 职责

ServerExpansion 是 ZerOS 的服务管理模块，负责：
- **服务发现**：扫描 D/server 下的服务模块
- **服务加载**：加载服务模块代码
- **生命周期管理**：启动、停止服务
- **状态查询**：获取服务运行状态

### 1.2 服务目录

服务存储在 `D/server/` 目录下：

```
D/server/
├── server-myservice.js   # 服务模块
├── server-http.js        # HTTP 服务
└── ...
```

---

## 二、服务模块格式

### 2.1 五个生命周期方法

每个服务模块必须提供以下方法：

| 方法 | 说明 | 调用时机 |
|------|------|---------|
| `__init__` | 初始化 | 首次启动时 |
| `__start__` | 启动 | 每次启动时 |
| `__stop__` | 停止 | 停止服务时 |
| `__status__` | 状态 | 查询状态时 |
| `__info__` | 信息 | 获取服务信息时 |

### 2.2 示例

```javascript
// D/server/server-myservice.js

const MyService = {
    _running: false,
    
    __init__: async function() {
        // 初始化逻辑（如加载配置）
        console.log('Service initialized');
    },
    
    __start__: async function() {
        this._running = true;
        console.log('Service started');
    },
    
    __stop__: async function() {
        this._running = false;
        console.log('Service stopped');
    },
    
    __status__: function() {
        return { running: this._running };
    },
    
    __info__: function() {
        return {
            name: 'My Service',
            version: '1.0.0',
            description: '我的服务'
        };
    }
};

// 注册服务
window.__ZerOS_ServerExpansion_Register__(MyService);
```

---

## 三、核心 API

| 方法 | 说明 |
|------|------|
| `loadAll()` | 加载所有服务模块 |
| `start(id)` | 启动服务 |
| `stop(id)` | 停止服务 |
| `status(id)` | 获取服务状态 |
| `list()` | 列出所有服务 |

---

## 四、启动流程

### 4.1 完整流程

```
ServerExpansion 加载
      │
      ▼
扫描 D/server/*.js
      │
      ▼
加载服务模块代码
      │
      ▼
注册服务（__ZerOS_ServerExpansion_Register__）
      │
      ▼
用户调用 Server.start(id)
      │
      ▼
调用 __init__（仅首次）
      │
      ▼
调用 __start__
      │
      ▼
服务运行
```

---

## 本节小结

本节讲解了 ServerExpansion 服务扩展的实现：

1. **服务目录**：D/server 下存放服务模块
2. **模块格式**：必须提供五个生命周期方法
3. **生命周期**：init（仅首次）→ start → stop
