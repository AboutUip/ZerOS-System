---

## 一、语言扩展概述

### 1.1 职责

LanguagesExpansion 是 ZerOS 的多语言支持模块，提供：
- **语言包加载**：从文件系统加载语言包
- **语言切换**：动态切换系统语言
- **文本获取**：根据 key 获取当前语言的文本

### 1.2 语言包位置

语言包存储在 `D:/languages/` 目录下：

```
D:/languages/
├── zh-CN.json    # 中文简体
├── en-US.json    # 英文
├── ja-JP.json    # 日文
└── ...
```

### 1.3 语言包格式

```json
{
    "app.name": "ZerOS",
    "desktop.welcome": "欢迎使用 ZerOS",
    "file.notFound": "文件未找到",
    "dialog.confirm": "确认",
    "dialog.cancel": "取消"
}
```

## 三、实现要点

### 3.1 语言包加载

```javascript
static async loadLanguage(langCode) {
    const langPath = `D:/languages/${langCode}.json`;
    
    // 读取语言包文件
    const content = await FileSystem.readFile(langPath);
    const langData = JSON.parse(content);
    
    // 存储到内存
    this._languages[langCode] = langData;
    
    KernelLogger.info('LanguagesExpansion', `语言包已加载: ${langCode}`);
}
```

### 3.2 文本获取

```javascript
static getText(key, params = {}) {
    const langCode = this._currentLanguage;
    const langData = this._languages[langCode] || {};
    
    let text = langData[key] || key; // 未找到则返回 key
    
    // 替换参数
    Object.keys(params).forEach(param => {
        text = text.replace(`{${param}}`, params[param]);
    });
    
    return text;
}
```
