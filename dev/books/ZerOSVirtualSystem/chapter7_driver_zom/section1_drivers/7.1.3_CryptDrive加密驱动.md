# 7.1.3 CryptDrive 加密驱动

## 本节导读

本节使读者能够：**① 理解 CryptDrive 的职责——提供加密解密、哈希、随机数等密码学功能；② 掌握 RSA 密钥对的生成、导入、使用流程；③ 理解密钥管理机制——密钥存储、默认密钥、过期时间。** 源码位置：`kernel/drive/cryptDrive.js`。

---

## 一、加密驱动概述

### 1.1 职责

CryptDrive 是 ZerOS 的加密服务模块，提供：
- **RSA 加密解密**：非对称加密
- **密钥管理**：生成、导入、删除密钥
- **哈希计算**：MD5、SHA 等
- **随机数生成**：整数、浮点、字符串、数组打乱

### 1.2 依赖

- jsencrypt 库：RSA 加密实现
- CryptoJS：MD5、SHA 哈希实现

## 二、核心 API

### 2.1 密钥管理

| 方法 | 说明 |
|------|------|
| `generateKeyPair(options)` | 生成 RSA 密钥对 |
| `importKeyPair(publicKey, privateKey, options)` | 导入密钥对 |
| `getKeyInfo(keyId)` | 获取密钥信息 |
| `listKeys()` | 列出所有密钥 |
| `deleteKey(keyId)` | 删除密钥 |
| `setDefaultKey(keyId)` | 设置默认密钥 |

### 2.2 加解密

| 方法 | 说明 |
|------|------|
| `encrypt(data, keyId, publicKey)` | 加密数据 |
| `decrypt(encryptedData, keyId, privateKey)` | 解密数据 |

### 2.3 工具函数

| 方法 | 说明 |
|------|------|
| `md5(data)` | MD5 哈希 |
| `randomInt(min, max)` | 随机整数 |
| `randomFloat(min, max)` | 随机浮点数 |
| `randomString(length, chars)` | 随机字符串 |
| `randomChoice(array)` | 随机选择 |
| `shuffle(array)` | 打乱数组 |
