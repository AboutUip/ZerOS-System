# 第7.1节：系统驱动详解

## 本节导读

系统驱动是 ZerOS 内核功能扩展的重要组成部分。本节详细讲解驱动概述、加载机制，以及 CacheDrive、CryptDrive、NetworkManager 等核心驱动的实现。

## 学习目标

完成本节学习后，读者应能够：
1. 理解 ZerOS 驱动的分类与加载机制
2. 掌握核心驱动的实现原理
3. 能够自行开发新的驱动
