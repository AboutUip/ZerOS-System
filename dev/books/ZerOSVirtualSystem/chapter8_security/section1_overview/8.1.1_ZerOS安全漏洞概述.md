# 8.1.1 ZerOS 安全漏洞概述

## 本节导读

本节使读者能够：**① 理解 ZerOS 安全漏洞报告体系的建立背景；② 掌握漏洞编号规则（CVS-ZEROS）；③ 了解 ZerOS 安全审计的方法论。**

---

## 一、漏洞报告体系

### 1.1 建立背景

ZerOS 作为运行在浏览器端的虚拟操作系统，虽然不涉及真实硬件，但仍然面临多种安全挑战：

- **前端代码执行**：恶意程序可能尝试提权
- **数据泄露**：敏感信息可能被未授权访问
- **后端攻击**：远程服务器可能遭受攻击
- **权限滥用**：程序可能尝试获取超出其权限的操作能力

### 1.2 漏洞编号规则

ZerOS 使用 CVS-ZEROS 编号体系：

```
CVS-ZEROS-XXX

CVS: ZerOS Security Vulnerability
XXX: 序号（001-999）
```
