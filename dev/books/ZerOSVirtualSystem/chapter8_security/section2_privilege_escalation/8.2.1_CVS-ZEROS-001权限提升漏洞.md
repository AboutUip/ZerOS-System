# 8.2.1 CVS-ZEROS-001: 权限提升漏洞

## 漏洞概述

**漏洞编号**: CVS-ZEROS-001  
**严重程度**: 严重 (CVSS 9.1)  
**状态**: 已修复

### 漏洞描述

ProcessManager.PROCESS_TABLE 可被直接修改，PermissionManager 权限检查依赖可被篡改的 isExploit 标志。

### 攻击方式

```javascript
const processTable = ProcessManager.PROCESS_TABLE;
const processInfo = processTable.get(currentPid);
processInfo.isExploit = true; // 直接修改
processTable.set(currentPid, processInfo);
```

### 修复方案

1. **PROCESS_TABLE 保护**：返回副本而非原始 Map
2. **isExploit 验证**：通过内核内部状态校验
3. **调用栈检查**：验证调用来源是否合法

---

## 本节小结

1. **漏洞**：可修改进程表获取管理员权限
2. **修复**：返回副本、内部状态校验
