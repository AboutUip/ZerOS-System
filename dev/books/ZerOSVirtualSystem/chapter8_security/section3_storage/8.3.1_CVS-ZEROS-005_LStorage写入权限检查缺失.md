# 8.3.1 CVS-ZEROS-005: LStorage 写入权限检查缺失

## 漏洞概述

**漏洞编号**: CVS-ZEROS-005  
**严重程度**: 严重 (CVSS 8.8)  
**状态**: 已修复

### 漏洞描述

LStorage.setSystemStorage() 方法在写入系统存储数据时，没有对存储键进行权限验证。

### 攻击方式

```javascript
// 获得 SYSTEM_STORAGE_WRITE 权限后
await LStorage.setSystemStorage('userControl.users', {
    username: 'attacker',
    password: '...', // 设置已知密码
    isAdmin: true
});
```

### 修复方案

1. **敏感键分类**：将存储键分为普通键和敏感键
2. **权限细分**：敏感键需要更高权限（如 SYSTEM_STORAGE_WRITE_USER_CONTROL）
3. **调用栈验证**：验证调用是否来自内核模块

---

## 本节小结

1. **漏洞**：系统存储写入时未验证存储键权限
2. **修复**：敏感键需要额外权限
