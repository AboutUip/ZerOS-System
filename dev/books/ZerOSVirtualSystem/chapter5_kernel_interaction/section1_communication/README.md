# 5.1 模块间通信机制

## 大节简介

本节讲解 ZerOS 中**模块间通信**的三种主要机制：**POOL** 作为全局注册表供模块“按名发现”其他模块或单例；**KernelMemory** 作为跨模块的共享持久化状态（进程表、内存分区元数据、磁盘分区名等）；**事件**（如 dependencyLoaded、自定义 CustomEvent）作为“就绪信号”或解耦通知。学完后能明确“谁通过什么方式拿到谁”的路径。
