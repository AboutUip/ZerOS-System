# 4.5.9 情景：使用 Crypt.* 管理密钥与加解密

## 情景描述

某些应用需要对敏感数据（如 token、配置、用户信息）做**加密存储或传输**，同时又希望统一管理密钥、做简单的随机数/哈希。  

ZerOS 中的 `CryptDrive` 提供这些能力，对外暴露为 `Crypt.*` 系列 API：  
`Crypt.generateKeyPair / Crypt.importKeyPair / Crypt.getKeyInfo / Crypt.listKeys / Crypt.deleteKey / Crypt.setDefaultKey / Crypt.encrypt / Crypt.decrypt / Crypt.md5 / Crypt.random* / Crypt.shuffle` 等。

本节用三个情景说明：**生成与存储密钥对**、**用默认密钥加解密数据**、以及**使用随机数/哈希工具函数**。

---

## 前置条件

- 应用持有 `this.pid`。  
- `CryptDrive` 已初始化（系统会在内核层加载它并从 LStorage 读入密钥数据）。  
- 若涉及系统级密钥（存放在 LStorage 系统存储中），通常只对受信任应用或系统工具开放。  

---

## 情景 A：生成一对密钥并设为默认

```js
async function setupCrypto() {
    // 1. 生成密钥对（options 结构由 CryptDrive.generateKeyPair 决定）
    const keyPair = await ProcessManager.callKernelAPI(this.pid, 'Crypt.generateKeyPair', [{
        description: '应用启动生成的默认密钥',
        tags: ['app-default', 'rsa'],
        // 还可以有 keySize、expiresAt 等字段，以实际实现为准
    }]);

    const keyId = keyPair && keyPair.keyId;
    if (!keyId) {
        throw new Error('生成密钥对失败：未返回 keyId');
    }

    // 2. 将该 key 设为默认密钥
    await ProcessManager.callKernelAPI(this.pid, 'Crypt.setDefaultKey', [keyId]);

    // 3. 可选：查看一下 key 信息
    const info = await ProcessManager.callKernelAPI(this.pid, 'Crypt.getKeyInfo', [keyId]);
    console.log('新密钥信息:', info);
}
```

要点：  
- `Crypt.generateKeyPair` 参数是 `[options]`；`options` 会被传给 `CryptDrive.generateKeyPair`。  
- 返回结构中通常包含 `keyId`、`publicKey`、`privateKey` 等字段（以 CryptDrive 实现为准）。  
- `Crypt.setDefaultKey` 参数是 `[keyId]`。

## 情景 B：用默认密钥对数据加密与解密

```js
async function encryptConfig(configObject) {
    const plainText = JSON.stringify(configObject);

    // 不指定 keyId，使用默认密钥；如果需要也可以传入显式 keyId 或公钥
    const encrypted = await ProcessManager.callKernelAPI(this.pid, 'Crypt.encrypt', [
        plainText,
        null,   // keyId（null 表示使用默认 key）
        null    // publicKey（可选）
    ]);

    return encrypted; // 具体结构由 CryptDrive.encrypt 决定（可能是字符串或对象）
}

async function decryptConfig(encryptedData) {
    const decrypted = await ProcessManager.callKernelAPI(this.pid, 'Crypt.decrypt', [
        encryptedData,
        null,   // keyId（null 表示使用默认 key）
        null    // privateKey（可选）
    ]);

    try {
        return JSON.parse(decrypted);
    } catch {
        throw new Error('解密后的配置不是合法 JSON');
    }
}
```

要点：  
- `Crypt.encrypt` 的参数是 `[data, keyId, publicKey]`；`Crypt.decrypt` 的参数是 `[encryptedData, keyId, privateKey]`。  
- 如果不传 `keyId`，由 CryptDrive 自己选择默认密钥；也可以显式传入外部公钥/私钥。

## 情景 C：使用随机数与哈希工具函数

```js
async function createRandomToken() {
    // 生成一个由字母和数字组成的 32 位随机字符串
    const token = await ProcessManager.callKernelAPI(this.pid, 'Crypt.randomString', [
        32,
        'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789'
    ]);
    return token;
}

async function hashPayload(payload) {
    const json = JSON.stringify(payload);
    const md5 = await ProcessManager.callKernelAPI(this.pid, 'Crypt.md5', [json]);
    return md5; // 具体格式由 CryptDrive.md5 决定（通常是 32 位十六进制字符串）
}

async function pickRandomElement(list) {
    const choice = await ProcessManager.callKernelAPI(this.pid, 'Crypt.randomChoice', [list]);
    return choice;
}
```

你还可以使用：  
- `Crypt.randomInt(min, max)`：生成指定范围内的整数；  
- `Crypt.randomFloat(min, max)`：生成浮点数；  
- `Crypt.randomBoolean()`：生成布尔值；  
- `Crypt.shuffle(array)`：打乱数组顺序。  

---

## 行为小结

| API | 典型 args | 用途 |
|-----|-----------|------|
| `Crypt.generateKeyPair` | `[options]` | 生成一对密钥，并存入 CryptDrive 内部管理结构 |
| `Crypt.importKeyPair` | `[publicKey, privateKey, options]` | 导入已有密钥对 |
| `Crypt.getKeyInfo` | `[keyId]` | 查看某个 key 的元数据 |
| `Crypt.listKeys` | `[]` | 列出所有已知 key |
| `Crypt.deleteKey` | `[keyId]` | 删除指定 key |
| `Crypt.setDefaultKey` | `[keyId]` | 设置默认 key |
| `Crypt.encrypt` | `[data, keyId, publicKey]` | 使用指定或默认密钥加密数据 |
| `Crypt.decrypt` | `[encryptedData, keyId, privateKey]` | 解密数据 |
| `Crypt.md5` | `[data]` | 计算 MD5 哈希 |
| `Crypt.random*` / `Crypt.shuffle` | 见上文示例 | 通用随机数与数组工具 |

通过这些情景，你可以把 `Crypt.*` 看作 ZerOS 提供的“统一加密与随机数服务”：  
密钥落在内核/系统存储中集中管理，而应用只需通过 `callKernelAPI` 调用高层 API 即可完成大部分安全相关操作。
