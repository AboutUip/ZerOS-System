# 4.5 系统 API 使用情景（应用层）

## 大节简介

本节从“**应用开发者**”视角，成体系地讲解 ZerOS **系统/内核 API 的实际用法**。不做接口清单，而是用一组**真实情景 + 少量核心代码**，让你看懂：如何拿到 `pid`、如何通过 `ProcessManager.callKernelAPI` 调用各类系统能力、需要哪些权限、以及出错时如何处理。

情景覆盖：**系统通知、持久化数据、退出前保存与自退、事件与跨窗口通信、任务栏与前后台切换** 等，后续还可以继续扩展更多 API 的使用案例。
