# 4.1.2 GUIManager 职责与窗口注册

## 本节导读（阅读目标）

本节使读者能够：**① 完全理解 GUIManager 的职责：窗口注册表、z-index 分配与回收、焦点与模态对话框、与 ProcessManager/任务栏的协作；② 明确 _windows、_pidToWindows、_focusedWindowId、_previewProviders 等数据结构及 registerWindow/unregisterWindow 的完整流程；③ 掌握 _generateWindowId、z-index 超限时的重新分配、弹性内容（iframe）的尺寸处理；④ 接手维护时能正确扩展窗口选项、排查“窗口被挡住”或“进程退出后窗口未移除”。** 源码文件：`system/ui/guiManager.js`。

---

## 一、GUIManager 的职责与依赖

GUIManager 在 MODULE_DEPENDENCIES 中依赖 **processManager** 与 **eventManager**。职责概括：

1. **窗口注册与生命周期**：程序通过内核 API 调用 `registerWindow(pid, windowElement, options)`，传入窗口 DOM 元素与 title、icon、onClose 等；GUIManager 分配 windowId、z-index，将窗口加入 _windows 与 _pidToWindows，并挂载关闭/最小化/最大化等控件。
2. **z-index 与层叠**：新窗口获得当前最大 z-index + 1；当 _currentZIndex 达到 _maxZIndex（99999，任务栏为 99999 需在窗口之上）时，对所有窗口重新分配 z-index 保持相对顺序，避免溢出。
3. **焦点与模态**：点击窗口时置为焦点并提到最前；模态对话框显示时备份非模态窗口透明度并降低其透明度，关闭模态时恢复。
4. **任务栏预览**：程序可调用 `registerTaskbarPreviewProvider(pid, { getPreviewContent, onPreviewClick })`，任务栏悬停该 pid 图标时用 getPreviewContent() 的 HTML 片段渲染预览，点击由 onPreviewClick 处理。
5. **与 ProcessManager 的协作**：窗口与 pid 绑定；进程退出时需调用 `unregisterAllWindowsByPid(pid)` 移除该进程所有窗口并从 DOM 移除。

## 三、init、POOL 注册与 ThemeManager（约 37–84 行）

```javascript
    static init() {
        if (GUIManager._initialized) return;
        GUIManager._initialized = true;

        if (typeof ThemeManager !== 'undefined') {
            ThemeManager.onStyleChange((styleId, style) => {
                GUIManager._updateWindowControlIcons();
                GUIManager._updateAllWindowsStyles();
            });
            ThemeManager.onThemeChange((themeId, theme) => {
                GUIManager._updateAllWindowsStyles();
            });
        }

        if (typeof POOL !== 'undefined' && typeof POOL.__ADD__ === 'function') {
            if (!POOL.__HAS__("KERNEL_GLOBAL_POOL")) POOL.__INIT__("KERNEL_GLOBAL_POOL");
            POOL.__ADD__("KERNEL_GLOBAL_POOL", "GUIManager", GUIManager);
        }
    }
```

主题/风格变更时更新所有窗口的控制按钮图标与样式；GUIManager 注册到 POOL 供其他模块通过 `POOL.__GET__("KERNEL_GLOBAL_POOL", "GUIManager")` 获取。

## 四、registerWindow 核心流程（约 276–350+ 行）

```javascript
    static registerWindow(pid, windowElement, options = {}) {
        GUIManager.init();
        if (!pid || !windowElement) return null;

        // 弹性内容（iframe）：固定初始宽高与 minWidth/minHeight，避免被内容撑开
        const isFlexibleContent = GUIManager._detectFlexibleContent(windowElement);
        if (isFlexibleContent.isFlexible) {
            windowElement.style.setProperty('width', '600px', 'important');
            windowElement.style.setProperty('height', '450px', 'important');
            windowElement.style.minWidth = '600px';
            windowElement.style.minHeight = '450px';
            // requestAnimationFrame 二次确保尺寸
        }

        const windowId = options.windowId || GUIManager._generateWindowId(pid);
        if (GUIManager._windows.has(windowId)) GUIManager.unregisterWindow(windowId);

        // z-index：取当前所有窗口最大 z-index + 1
        let maxZIndex = GUIManager._baseZIndex;
        for (const [, info] of GUIManager._windows) {
            if (info.zIndex > maxZIndex) maxZIndex = info.zIndex;
        }
        GUIManager._currentZIndex = maxZIndex + 1;
        if (GUIManager._currentZIndex >= GUIManager._maxZIndex) {
            // 重新分配所有窗口 z-index，保持相对顺序
            const sorted = Array.from(GUIManager._windows.entries()).sort((a, b) => a[1].zIndex - b[1].zIndex);
            let newZ = GUIManager._baseZIndex + 1;
            for (const [, info] of sorted) {
                info.zIndex = newZ++;
                if (info.window && info.window.style) info.window.style.setProperty('z-index', info.zIndex, 'important');
            }
            GUIManager._currentZIndex = newZ;
        }

        const windowInfo = {
            windowId, window: windowElement, pid,
            zIndex: GUIManager._currentZIndex,
            isFocused: false, isMinimized: false, isMaximized: false,
            title: options.title || '', icon: options.icon || '',
            createdAt: Date.now(), logs: []
        };
        GUIManager._windows.set(windowId, windowInfo);
        if (!GUIManager._pidToWindows.has(pid)) GUIManager._pidToWindows.set(pid, new Set());
        GUIManager._pidToWindows.get(pid).add(windowId);

        // 将窗口元素挂载到 DOM、绑定标题栏拖拽/点击聚焦、添加关闭/最小化/最大化按钮等（具体见源码）
        // ...
        return windowInfo;
    }
```

**行为流程**：init → 弹性内容则设尺寸 → 生成或复用 windowId、若存在则先 unregister → 计算新 z-index，超限则全局重排 → 构造 WindowInfo 写入 _windows 与 _pidToWindows → 挂载 DOM 与控件 → 返回 windowInfo。

## 五、unregisterWindow 与 unregisterAllWindowsByPid

- **unregisterWindow(windowId)**：从 _windows 取 windowInfo，从 _pidToWindows[pid] 移除 windowId，若 _focusedWindowId === windowId 则清空焦点，从 DOM 移除 window 元素，delete _windows[windowId]，调用 onClose 回调（若有）。
- **unregisterAllWindowsByPid(pid)**：取 _pidToWindows.get(pid)，对每个 windowId 调用 unregisterWindow(windowId)，最后 delete _pidToWindows[pid]。进程退出时由上层调用，保证该进程所有窗口被移除。

---

## 六、行为流程小结（从注册到关闭）

1. 程序创建窗口 DOM 后通过内核 API 调用 GUIManager.registerWindow(pid, element, { title, icon, onClose })；GUIManager 分配 windowId 与 z-index，写入 _windows/_pidToWindows，挂载到 DOM。  
2. 用户点击窗口标题栏时，该窗口置为焦点并 z-index 提到最前；关闭按钮触发 onClose 或直接 unregisterWindow。  
3. 进程退出时调用 unregisterAllWindowsByPid(pid)，该 pid 下所有窗口被 unregisterWindow，DOM 移除且 _windows/_pidToWindows 更新。

---

## 七、接手维护要点

- **“窗口被挡住”**：检查 z-index 是否被其他样式覆盖（GUIManager 使用 setProperty(..., 'important')）；检查 _maxZIndex 与任务栏 z-index 是否冲突。  
- **“进程退出后窗口未移除”**：确认进程退出路径调用了 GUIManager.unregisterAllWindowsByPid(pid)；若 ProcessManager 退出逻辑未调用，需在 ProcessManager 或统一清理处添加。  
- **扩展窗口选项**：在 registerWindow 的 options 中增加字段，在 WindowInfo 与标题栏/控件渲染处使用；onClose/onMinimize/onMaximize 由调用方传入，GUIManager 只负责在适当时机调用。
