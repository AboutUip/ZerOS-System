# 4.2 任务栏与通知

## 大节简介

本节讲解 **TaskbarManager**（`system/ui/taskbarManager.js`）与 **NotificationManager**（`system/ui/notificationManager.js`）。任务栏负责渲染常显程序与正在运行程序的图标、开始菜单、系统托盘、天气等，与 ProcessManager/GUIManager 协作；通知管理器负责系统通知的显示、队列、动画与多语言文案。
