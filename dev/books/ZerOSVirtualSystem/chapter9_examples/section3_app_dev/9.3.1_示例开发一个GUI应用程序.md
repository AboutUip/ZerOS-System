# 9.3.1 示例：开发一个 GUI 应用程序

## 本节导读

本节通过示例讲解如何开发一个 ZerOS GUI 应用程序。

---

## 项目概述

创建一个简单的"便签"应用程序，可以在桌面创建便签窗口。

---

## 实现步骤

### 1. 创建应用入口

```javascript
// main.js

(function() {
    'use strict';
    
    const NoteApp = {
        windowId: null,
        
        async init() {
            // 创建窗口
            this.windowId = await GUIManager.createWindow({
                title: '便签',
                width: 300,
                height: 200,
                x: 100,
                y: 100,
                resizable: true
            });
            
            // 渲染内容
            this.render();
        },
        
        render() {
            const content = `
                <div style="padding: 10px;">
                    <textarea id="note-content" style="width: 100%; height: 150px;"></textarea>
                    <button id="save-btn">保存</button>
                </div>
            `;
            
            GUIManager.setWindowContent(this.windowId, content);
            
            // 绑定事件
            document.getElementById('save-btn').onclick = () => this.save();
        },
        
        async save() {
            const content = document.getElementById('note-content').value;
            await FileSystem.writeFile('D:/note.txt', content);
            Notification.show('已保存');
        }
    };
    
    // 启动应用
    window.addEventListener('load', () => NoteApp.init());
})();
```

---

## 本节小结

1. **创建窗口**：使用 GUIManager.createWindow
2. **渲染内容**：设置窗口 HTML 内容
3. **事件处理**：绑定按钮事件
