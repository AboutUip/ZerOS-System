# 9.3.2 示例：开发一个控制台应用程序

## 本节导读

本节通过示例讲解如何开发一个 ZerOS 控制台应用程序。

---

## 项目概述

创建一个简单的"计算器"命令行工具。

---

## 实现步骤

### 1. 创建应用入口

```javascript
// main.js

(function() {
    'use strict';
    
    const Calculator = {
        async init(args) {
            // 解析参数: calc add 1 2
            const command = args[0];
            const a = parseFloat(args[1]);
            const b = parseFloat(args[2]);
            
            let result;
            
            switch(command) {
                case 'add':
                    result = a + b;
                    break;
                case 'sub':
                    result = a - b;
                    break;
                case 'mul':
                    result = a * b;
                    break;
                case 'div':
                    result = b !== 0 ? a / b : 'Error: Division by zero';
                    break;
                default:
                    console.log('用法: calc <add|sub|mul|div> <a> <b>');
                    return;
            }
            
            console.log('结果:', result);
        }
    };
    
    // 导出模块
    window.APP = Calculator;
})();
```

---

## 本节小结

1. **参数解析**：从 args 数组获取命令行参数
2. **计算逻辑**：根据命令执行相应运算
3. **输出结果**：使用 console.log 输出
