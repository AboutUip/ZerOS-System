# 9.2.1 示例：开发一个简单的系统工具

## 本节导读

本节通过示例讲解如何开发一个简单的 ZerOS 内核模块。

---

## 项目概述

创建一个系统工具模块，提供获取系统运行时间的功能。

---

## 实现步骤

### 1. 创建模块文件

```javascript
// kernel/system/systemUptime.js

class SystemUptime {
    static _startTime = Date.now();
    
    static getUptime() {
        return Date.now() - this._startTime;
    }
    
    static getUptimeFormatted() {
        const ms = this.getUptime();
        const seconds = Math.floor(ms / 1000);
        const minutes = Math.floor(seconds / 60);
        const hours = Math.floor(minutes / 60);
        const days = Math.floor(hours / 24);
        
        return `${days}天 ${hours % 24}小时 ${minutes % 60}分钟 ${seconds % 60}秒`;
    }
}

// 注册到 POOL
POOL.__SET__("KERNEL_GLOBAL_POOL", "SystemUptime", SystemUptime);
```

### 2. 注册到 MODULE_DEPENDENCIES

```javascript
// 在 starter.js 中添加
'kernel/system/systemUptime': ['kernel/drive/logger'],
```

### 3. 使用模块

```javascript
const SystemUptime = POOL.__GET__("KERNEL_GLOBAL_POOL", "SystemUptime");

console.log("系统运行时间:", SystemUptime.getUptimeFormatted());
```

---

## 本节小结

1. **模块结构**：创建类并注册到 POOL
2. **依赖配置**：在 MODULE_DEPENDENCIES 中声明依赖
3. **使用模块**：通过 POOL 获取模块实例
