# 9.4.1 示例：开发一个简单的系统驱动

## 本节导读

本节通过示例讲解如何开发一个 ZerOS 系统驱动。

---

## 项目概述

创建一个简单的"剪贴板"驱动，提供复制和粘贴功能。

---

## 实现步骤

### 1. 创建驱动文件

```javascript
// kernel/drive/clipboardDrive.js

class ClipboardDrive {
    static _clipboard = '';
    
    static setClipboard(text) {
        this._clipboard = String(text);
        KernelLogger.debug('ClipboardDrive', '已复制到剪贴板');
        return true;
    }
    
    static getClipboard() {
        return this._clipboard;
    }
    
    static clearClipboard() {
        this._clipboard = '';
        KernelLogger.debug('ClipboardDrive', '剪贴板已清空');
        return true;
    }
}

// 注册驱动
POOL.__SET__("KERNEL_GLOBAL_POOL", "ClipboardDrive", ClipboardDrive);
window.ClipboardDrive = ClipboardDrive;
```

### 2. 导出 kernelAPI

```javascript
// 在驱动初始化时导出
KernelAPI.defineAPI('Clipboard', {
    set: (text) => ClipboardDrive.setClipboard(text),
    get: () => ClipboardDrive.getClipboard(),
    clear: () => ClipboardDrive.clearClipboard()
});
```

### 3. 使用驱动

```javascript
// 应用中使用
await ProcessManager.callKernelAPI(this.pid, 'Clipboard.set', ['Hello World']);
const text = await ProcessManager.callKernelAPI(this.pid, 'Clipboard.get', []);
```
