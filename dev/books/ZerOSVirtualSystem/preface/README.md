# 序言

内核，一个只是读出来就感到兴奋敬畏的领域，它代表了数字化编程的极限。每一个全新内核架构的诞生，都是一次跨时代的进步。SCM首次将超底层集成为一个系统，诞生了真正意义的第一个内核，它带来了集成嵌入式开发的时代；UNIX首次将内核作为系统核心层，它带来了系统的核心分层架构这一事实标准，Linux、Windows等操作系统均基于该类架构；现在，内核概念的通用泛化，使其应用开始极速发散，引擎依赖内核，芯片依赖内核，服务也依赖内核，内核已经成为一个必不可少的技术概念了。

在嵌入式盛行的年代，掌握内核开发这项技能几乎是一个必须的条件，而当时学习内核开发的条件也很困难。我们常说学习一个技能最好的办法就是参考一个项目，但当时很多内核项目都是闭源，没有可供直接参考的实现，学习曲线也相当陡峭。那么AI盛行的现代呢，我们可以参考很多芯片底层的内核实现，也可以参考Linux的内核实现，国内还有很多形式的内核组织架构可供参考学习，但这些都有缺点：

1. 没有详细可参考的文档与解析
2. 代码量庞大，几乎不可能单点查看运行状态
3. 严格环境要求，无法支持学习性质的快速启停
4. 项目即使开源，也依旧面临过于庞大或者某些行为处于黑盒的问题

例如Linux内核，即使有资料和社区支持，单人独立掌握Linux内核的全貌并从中学习到内核的精髓仍然是不可能的。基于这些问题，我们创造了一个虚拟的操作系统，用模拟代替实现，舍弃可用性换来的最佳学习性质。

这个虚拟系统（之后简称“系统”，不在赘述）包含了真实操作系统的大部分内容，boot引导层，kernel内核层，system系统层，整个系统运行在浏览器环境下，完美沙盒环境符合教学的实时查阅与即时数据更新，部署与备份效率都高于常规教学项目，特别是该系统全面采用JavaScript进行开发，学习门槛低，一切行为逻辑均可控无黑盒。

本书不会讲解通用的内核知识，而是会围绕这个系统详细讲解其内部逻辑与架构，希望你可以通过本书窥探到内核这个概念的庐山“真面目”。本书的后几章，会围绕ZDK与Server相关内容展开，末尾会讨论一些前沿技术，例如AI协同开发大型项目是否可行，对此感兴趣的读者可以翻阅到相关章节。

本书适合内核学习教材，驱动编程的引导入门教材，应用程序与SDK的交互编程入门教材，服务支持入门教材，JavaScript编程能力提升参考。

这个系统耗费了作者很多心血，希望这个系统可以帮助到各位读者，Good Luck。
