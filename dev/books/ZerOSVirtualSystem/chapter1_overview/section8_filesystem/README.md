# 1.8 文件系统——数据的持久化

## 大节简介

文件系统是操作系统负责数据持久化的核心组件，它管理磁盘上的数据存储和检索。

本节将介绍文件系统的核心概念，以及 ZerOS 中文件系统的实现方式。

本节作为概述性内容，详细实现原理将在第3章深入讲解。

## 核心问题

**为什么要引导文件系统？它在引导流程中起什么作用？**

文件系统是数据的"保管员"，它负责数据的持久化存储。在引导流程中，系统需要从文件系统中读取配置和数据。
