# 1.5 模块加载器——按序初始化

## 大节简介

模块加载器是 ZerOS 启动流程中的核心组件，它负责按照正确的顺序加载和初始化所有内核模块。

本节将介绍模块加载的核心概念，以及 ZerOS 中模块加载器的使用方式。

本节作为概述性内容，详细实现原理将在第2章深入讲解。

## 核心问题

**为什么要引导模块加载器？它在引导流程中起什么作用？**

模块加载器是引导流程的"执行者"，它按照依赖配置确定的顺序加载所有模块。没有模块加载器，其他模块无法被加载到系统中。
