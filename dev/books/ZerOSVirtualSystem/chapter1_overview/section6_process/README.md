# 1.6 进程管理——程序的运行管理

## 大节简介

进程管理是操作系统的核心功能之一，它负责管理系统中运行的程序。

本节将介绍进程管理的核心概念，以及 ZerOS 中进程管理的实现方式。

本节作为概述性内容，详细实现原理将在第3章深入讲解。

## 核心问题

**为什么要引导进程管理？它在引导流程中起什么作用？**

进程管理是程序的"生命周期管家"，它管理系统中所有程序的启动、运行和终止。在引导流程中，许多模块需要以进程形式运行。
