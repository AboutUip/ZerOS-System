# 1.4 对象池——模块间的数据共享

## 大节简介

对象池是 ZerOS 启动流程中的重要机制，它负责在模块之间共享数据和对象。

本节将介绍对象池的核心概念，以及 ZerOS 中对象池的使用方式。

本节作为概述性内容，详细实现原理将在第2章深入讲解。

## 核心问题

**为什么要引导对象池？它在引导流程中起什么作用？**

对象池是模块间的"数据桥梁"，它提供了统一的共享空间，让不同模块可以相互访问数据。没有对象池，模块之间的数据传递将变得困难。
