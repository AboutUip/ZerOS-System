# 1.11 事件系统——用户交互的处理

## 大节简介

事件系统是 ZerOS 系统中模块间通信的核心机制，它负责处理用户交互和模块间通信。

本节将介绍事件系统的核心概念，以及 ZerOS 中事件系统的实现方式。

本节作为概述性内容，详细实现原理将在第4章深入讲解。

## 核心问题

**为什么要引导事件系统？它在引导流程中起什么作用？**

事件系统是系统的"神经网络"，它负责传递信息和处理用户交互。在引导流程中，事件系统让各个模块能够相互通信和协调工作。
