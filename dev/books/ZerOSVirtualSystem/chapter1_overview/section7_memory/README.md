# 1.7 内存管理——内存资源的分配

## 大节简介

内存管理是操作系统的核心功能之一，它负责管理系统中的内存资源。

本节将介绍内存管理的核心概念，以及 ZerOS 中内存管理的实现方式。

本节作为概述性内容，详细实现原理将在第3章深入讲解。

## 核心问题

**为什么要引导内存管理？它在引导流程中起什么作用？**

内存管理是系统的"资源管家"，它负责分配和回收内存资源。在引导流程中，许多模块需要分配内存来存储数据。
