# 1.10 GUI窗口管理——用户界面的呈现

## 大节简介

GUI窗口管理是操作系统负责图形用户界面窗口显示和交互的核心组件。

本节将介绍GUI窗口管理的核心概念，以及 ZerOS 中GUI窗口管理的实现方式。

本节作为概述性内容，详细实现原理将在第4章深入讲解。

## 核心问题

**为什么要引导GUI窗口管理？它在引导流程中起什么作用？**

GUI窗口管理是系统的"门面"，它负责显示图形界面。在引导流程后期，系统需要显示GUI界面来与用户交互。
