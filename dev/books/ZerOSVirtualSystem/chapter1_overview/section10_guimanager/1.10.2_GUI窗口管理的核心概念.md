# 1.10.2 GUI窗口管理的核心概念

## 本节导读

本节将介绍 GUI 窗口管理的核心概念，重点是**窗口**这一抽象以及对其的**基本操作**。ZerOS 通过 GUIManager 管理窗口的创建、布局与生命周期，本节建立的概念是理解其 API 与行为的基础。

---

## 窗口操作

### 基本操作

**窗口**是用户与系统交互的主要载体，通常对应屏幕上的一个可移动、可调整大小的矩形区域，内部承载应用界面或系统 UI。对窗口的**基本操作**包括：

- **最小化**：将窗口从当前工作区收起，不关闭应用，仅在任务栏或窗口列表中保留入口，需要时可再次展开。用于临时让出屏幕空间而不中断任务。
- **最大化**：将窗口扩展为占满可用工作区（或全屏），便于专注单任务或充分利用显示区域。再次操作可恢复为之前的尺寸和位置。
- **关闭**：结束该窗口对应的应用或视图，释放相关资源。关闭前可能触发“未保存是否确认”等逻辑，由应用与窗口管理器协同处理。
- **移动与调整大小**：用户通过拖拽标题栏或边框改变窗口位置和尺寸，窗口管理器负责重绘与布局，并可能约束最小/最大尺寸或保持宽高比。

此外，**焦点**管理也属于窗口管理的核心能力：同一时刻通常只有一个窗口（或控件）拥有“焦点”，键盘输入和部分操作会发送给焦点窗口。GUIManager 需维护焦点顺序（如 Tab 切换）、点击时的焦点切换以及与模态窗口、弹窗的配合。

---

## 本节小结

本节介绍了 GUI 窗口管理的核心概念：窗口是用户交互的载体，对其的**基本操作**包括最小化、最大化、关闭以及移动与调整大小；**焦点**管理决定输入与操作的归属。这些概念在 ZerOS 的 GUIManager 中会有对应的实现与接口。
