# 1.3 依赖配置——模块关系的定义

## 大节简介

依赖配置是 ZerOS 启动流程中的关键环节，它负责定义模块之间的依赖关系，确保各模块按照正确的顺序加载和初始化。

本节将介绍依赖配置的核心能力，以及 ZerOS 中依赖配置的使用方式。

本节作为概述性内容，详细实现原理将在第2章深入讲解。

## 核心问题

**为什么要引导依赖配置？它在引导流程中起什么作用？**

依赖配置是模块加载的"调度中心"，它决定了哪些模块需要先加载，哪些模块依赖哪些模块。没有依赖配置，模块加载将陷入混乱。
