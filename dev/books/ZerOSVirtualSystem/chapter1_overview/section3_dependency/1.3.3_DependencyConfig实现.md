# 1.3.3 DependencyConfig 实现

## 本节导读

本节将介绍 ZerOS 中依赖配置的具体实现。

---

## DependencyConfig 核心架构

### 模块定位

DependencyConfig 是 ZerOS 的依赖配置核心模块。

### 核心功能

DependencyConfig 提供以下核心功能：

添加依赖项：声明模块需要哪些依赖
等待依赖就绪：等待依赖模块加载完成
查询依赖状态：检查依赖是否已就绪

---

## 依赖声明方式

### 声明格式

DependencyConfig 使用数组声明依赖：

```javascript
dependency.addDependency("moduleA.js");
dependency.addDependency(["moduleB.js", "moduleC.js"]);
```

### 声明位置

依赖通常在模块开头声明，确保加载器能够正确处理。

---

## 状态查询接口

### 查询方法

可以通过 API 查询依赖状态：

checkDependency()：检查依赖是否已加载
waitFor()：等待依赖就绪
getStatus()：获取依赖的详细状态
