# 课后思考参考答案

## 1.3.1 依赖配置的作用

1. 为什么依赖配置是引导流程的核心？
   - 管理模块依赖关系

2. 如果没有依赖配置会发生什么？
   - 加载顺序混乱

3. 依赖配置如何确定加载顺序？
   - 通过拓扑排序

## 1.3.2 依赖配置的核心概念

1. 依赖状态为什么需要分三个阶段？
   - linked、inited、loaded

2. 拓扑排序的作用是什么？
   - 确定加载顺序

3. 异步等待和同步等待各有什么优缺点？
   - 异步不阻塞，同步立即可用

## 1.3.3 DependencyConfig 实现

1. DependencyConfig 如何管理依赖状态？
   - 通过三态模型

2. 为什么要区分异步等待和同步等待？
   - 不同场景不同需求

3. 信号机制有什么作用？
   - 通知依赖就绪
