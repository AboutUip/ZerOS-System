# 1.9.3 PermissionManager 实现

## 本节导读

本节将介绍 ZerOS 中安全控制核心组件 PermissionManager 的实现要点。PermissionManager 与 UserControl 配合，实现权限检查与用户身份管理；详细实现见第 4 章，本节仅建立概述级认识。

---

## PermissionManager 在启动中的角色

### 功能概览

PermissionManager 在依赖图中通常依赖 ProcessManager、LStorage、UserControl 等，加载后向 **POOL** 注册，供应用启动、敏感 API 调用等场景使用。其提供的核心能力包括：

- **权限检查**：在程序请求敏感操作（如访问某类 API、读写某分区）时，根据当前用户与权限级别（NORMAL/SPECIAL/DANGEROUS）判断是否放行，对应 1.9.2 的三级权限。
- **与 UserControl 的配合**：用户身份、登录状态由 UserControl 管理；PermissionManager 在此基础上做“当前用户是否有权执行此操作”的裁决。
- **与进程的配合**：ProcessManager 启动应用时可能调用 PermissionManager 检查该应用或该操作是否被允许，实现“按进程/按操作”的权限控制。

### 与启动流程的关系

在启动流程图中，PermissionManager 位于系统层，在 LStorage、UserControl 等之后、锁屏与桌面之前。锁屏与登录流程依赖它来区分已登录用户与权限，因此其就绪是“安全地显示桌面与启动应用”的前提之一。

---

## 本节小结

本节概述了 PermissionManager 的职责：在引导流程中提供权限检查、与 UserControl 及 ProcessManager 配合，并向 POOL 注册供上层使用。具体权限模型与 API 见第 4 章。
