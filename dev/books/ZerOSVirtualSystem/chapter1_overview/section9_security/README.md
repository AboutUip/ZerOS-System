# 1.9 安全控制——权限与用户

## 大节简介

安全控制是操作系统保护系统安全的重要组件，它负责管理权限和用户认证。

本节将介绍安全控制的核心概念，以及 ZerOS 中安全控制的实现方式。

本节作为概述性内容，详细实现原理将在第4章深入讲解。

## 核心问题

**为什么要引导安全控制？它在引导流程中起什么作用？**

安全控制是系统的"门卫"，它管理系统权限和用户认证。在引导流程中，系统需要确保只有授权的模块和程序才能运行。
