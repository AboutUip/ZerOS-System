# 1.2 日志系统——调试的基础

## 大节简介

日志系统是任何软件系统不可或缺的基础设施。在操作系统中，日志系统承担着调试、监控、审计等重要职责。

本节将介绍日志系统的核心能力，以及 ZerOS 中日志系统的实现方式。

本节作为概述性内容，详细实现原理将在第2章深入讲解。
