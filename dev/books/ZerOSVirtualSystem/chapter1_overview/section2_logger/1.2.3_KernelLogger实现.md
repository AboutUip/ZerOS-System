# 1.2.3 KernelLogger 实现

## 本节导读

本节将介绍 ZerOS 中日志系统的具体实现方式。

---

## KernelLogger 核心架构

### 模块定位

KernelLogger 是 ZerOS 的日志系统核心，负责提供统一的日志记录接口。

作为系统中最先加载的模块，KernelLogger 被注册到全局作用域，供所有模块使用。

### 核心功能

KernelLogger 提供以下核心功能：

日志输出到控制台：使用 console.log 等方法输出
日志级别控制：通过设置日志级别过滤日志
日志格式化：添加时间戳、模块名等信息

---

## 日志级别的定义与应用

### 级别定义

KernelLogger 定义了多个日志级别：

DEBUG：调试信息，最详细的日志，用于开发调试
INFO：一般信息，系统正常运行记录
WARN：警告信息，可能存在问题但不影响运行
ERROR：错误信息，已经发生的问题
FATAL：致命错误，系统无法继续运行

### 级别应用

不同情况下使用不同的日志级别：

模块加载：使用 INFO 记录加载进度
详细初始化：使用 DEBUG 记录细节
发生错误：使用 ERROR 记录错误信息

---

## 与系统各模块的集成

### 集成方式

KernelLogger 通过以下方式与各模块集成：

全局可访问：所有模块可以直接调用 KernelLogger
依赖注入：通过 POOL 共享，供其他模块获取
事件集成：与事件系统配合，记录重要事件

### 使用示例

各模块使用 KernelLogger 记录日志：

```javascript
KernelLogger.info("Module loaded", { module: "ProcessManager" });
KernelLogger.error("Failed to load module", { error: err });
```
