# 课后思考参考答案

## 1.2.1 日志系统的作用

1. 为什么日志系统是最先被加载的模块之一？
   - 其他所有模块都需要使用日志功能

2. 日志系统如何帮助调试引导过程中的问题？
   - 记录每个模块的初始化状态

3. 如果没有日志系统，引导流程会面临哪些困难？
   - 问题难以排查

4. 日志系统与其他模块的依赖关系是怎样的？
   - 所有后续模块都直接或间接依赖于日志系统

5. 在引导过程中，应该选择什么样的日志级别？
   - 加载阶段用INFO，初始化用DEBUG，错误用ERROR

## 1.2.2 日志系统的核心能力

1. 日志级别有哪些？
   - DEBUG、INFO、WARN、ERROR

2. 日志存储需要注意哪些问题？
   - 大小限制、滚动策略

3. 如何平衡日志功能和性能？
   - 分级控制、异步写入

4. 异步日志写入有什么优势？
   - 不阻塞主流程

5. 日志格式化有什么作用？
   - 便于阅读和分析

## 1.2.3 KernelLogger 实现

1. KernelLogger 如何与各模块集成？
   - 全局可访问

2. 日志级别如何应用？
   - 不同情况使用不同级别

3. 为什么日志系统需要全局可访问？
   - 所有模块都需要记录日志
