# 1.1 内核的概念与歧义

## 大节简介

本节将澄清"内核"这一概念，消除读者对"内核"的绝对化理解。许多人将内核等同于 Linux 或 Windows NT 内核，认为内核必须是复杂的、底层的，与硬件直接交互的代码。本节将指出这种理解的局限性，并帮助读者建立对"内核"概念的更广义认知。同时，我们将解答为什么 ZerOS 采用 BootLoader 而非 Boot，以及为什么内核结构与常见操作系统不一致。

## 小节内容

### [1.1.1 什么是内核](1.1.1_什么是内核.md)

讲解内核的核心定义：资源管理器与抽象提供者，内核的核心职责，内核与应用程序的关系。

### [1.1.2 内核的绝对化理解](1.1.2_内核的绝对化理解.md)

常见的误解：内核 = Linux/Windows，为什么会有这种理解，以及这种理解的局限性。

### [1.1.3 为什么是 BootLoader 而非 Boot](1.1.3_为什么是BootLoader而非Boot.md)

讲解 BootLoader 与 Boot 的区别，以及在浏览器环境下为什么采用 BootLoader 这一术语。

### [1.1.4 为什么内核结构与常见操作系统不一致](1.1.4_为什么内核结构与常见操作系统不一致.md)

讲解 ZerOS 的内核结构与 Linux/Windows 的差异，分析浏览器环境对内核设计的影响。

### [1.1.5 内核的多样形态](1.1.5_内核的多样形态.md)

展示内核的多种形态：传统操作系统内核、虚拟机管理器、微内核、浏览器虚拟内核等。

### [1.1.6 本书的定位](1.1.6_本书的定位.md)

明确本书的目标：通过 ZerOS 这一具体案例，帮助读者理解内核的核心概念，而非追求精通某一特定内核。

### [1.1.7 系统分层与启动机制](1.1.7_系统分层与启动机制.md)

从引导概念出发，介绍 ZerOS 的三层架构：BootLoader → Kernel → System，理解各层职责与协作关系。

## 学习目标

- 理解内核的本质是"资源管理器"而非特定实现
- 认识到内核概念的多样性
- 理解 BootLoader 与 Boot 的区别
- 理解浏览器环境下内核设计的特殊性
- 明确本书的学习定位
- 理解 ZerOS 的三层架构与启动流程
