# 1.1.6 本书的定位

## 本节导读

本节将明确本书的定位与学习目标。作为面向 ZerOS 的教学用教材，本书有其独特的目标读者和学习路径，确保读者对本书有正确的预期。

---

## 1.1.6.1 本书的目标

### 理解而非精通

本书的首要目标是帮助读者**理解**操作系统的核心概念，而非追求**精通**某一特定内核。

操作系统是一个庞大的知识体系，涵盖进程调度、内存管理、文件系统、设备驱动、网络协议栈等众多领域。即便是 Linux 内核的专家，也不太可能精通所有领域。

本书采用 ZerOS 作为教学案例，目的是通过一个具体、可理解的系统，帮助读者建立对操作系统核心概念的直觉性理解。

### 建立系统级思维

本书的第二个目标是培养读者的**系统级思维**。

系统级思维是指能够从整体视角理解复杂系统各组件之间关系的能力。ZerOS 虽然是一个简化系统，但它完整地展示了操作系统的主要组件及其协作方式。

---

## 1.1.6.2 本书的局限

### 不是 Linux 内核教程

本书**不是** Linux 内核教程。

如果读者的目标是深入学习 Linux 内核开发，本书不是最佳选择。Linux 内核有其特定的设计模式、代码规范和开发流程，这些内容需要专门的书籍和课程来覆盖。

本书使用 ZerOS 作为案例，正是因为它**不是** Linux。ZerOS 的简洁性使得核心概念更容易理解。

### 不是 JavaScript 教程

本书**不是** JavaScript 编程教程。

本书假设读者已经具备 JavaScript 编程能力。虽然 ZerOS 使用 JavaScript 实现，但本书的重点是操作系统概念，而非 JavaScript 语法。

---

## 1.1.6.3 本书的学习路径

### 阶段一：建立整体认知（第1章）

第一阶段的目标是建立对 ZerOS 的整体认知。

本章将介绍 ZerOS 的启动流程概览，让读者了解系统有哪些核心模块，以及它们如何协作。

### 阶段二：深入核心模块（第2-4章）

第二阶段的目标是深入理解核心模块的实现。

第二章讲解 Boot 引导层，第三章讲解 Kernel 内核层，第四章讲解 System 系统层。这个阶段将配合源码进行分析。

### 阶段三：实践与扩展（第5章及以后）

第三阶段的目标是将知识转化为能力。

后续章节将涉及模块交互、后端服务、驱动开发等主题，帮助读者将理论知识应用于实践。

---

## 1.1.6.4 本节小结

本节明确了本书的定位。

本书的目标是帮助读者理解操作系统的核心概念、建立系统级思维。本书的局限在于它不是 Linux 内核教程或 JavaScript 教程。

理解本书的定位有助于读者建立正确的学习预期，从而更好地利用本书。
