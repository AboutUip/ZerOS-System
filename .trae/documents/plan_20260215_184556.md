# ZDOC 编辑功能扩展计划

## 一、当前状态分析

### 现有功能

* ✅ ZDOC 文件解析和预览

* ✅ 基础内容编辑（仅文本内容）

* ✅ 部分样式编辑（size, color, weight, width, padding, gap, direction, background）

* ✅ 文档保存

### 缺失功能

* ❌ 添加节点

* ❌ 删除节点

* ❌ 移动节点（调整顺序）

* ❌ 节点类型转换

* ❌ 添加/删除页面

* ❌ 完整的样式编辑

* ❌ 拖拽式编辑

***

## 二、架构设计

### 1. 数据模型扩展

#### 页面结构 (page.json)

```
structure: [
  { section_id: { id, type, child?, order? } }
]
```

需要添加：

* 节点操作 API：`addNode()`, `removeNode()`, `moveNode()`, `updateNode()`

* 节点工厂：自动生成唯一 ID

#### 2. Office 服务扩展 (`server-office.js` / `office-worker.js`)

新增 API：

* `addNode(pageIndex, parentId, nodeSpec, position)` - 添加节点

* `removeNode(pageIndex, nodeId)` - 删除节点

* `moveNode(pageIndex, nodeId, newParentId, newPosition)` - 移动节点

* `addPage()` - 添加页面

* `removePage(pageIndex)` - 删除页面

#### 3. Office 应用程序扩展 (`office.js`)

新增 UI：

* 工具栏按钮：添加节点、删除节点、添加页面

* 节点树视图面板

* 属性编辑器面板（完整样式编辑）

* 拖拽排序支持

***

## 三、具体实现步骤

### 第一阶段：核心数据结构

1. **扩展 page.json 操作函数**

   * `findNodeById()` - 查找节点

   * `addNodeToContainer()` - 添加节点到容器

   * `removeNodeFromContainer()` - 从容器删除节点

   * `updateNodeOrder()` - 更新顺序

2. **节点工厂**

   * `createNode(type, id?)` - 创建节点

   * `generateNodeId()` - 生成唯一 ID

### 第二阶段：服务层 API

1. **扩展 office-worker.js**

   * 添加 `addNode`, `removeNode`, `moveNode` 消息处理

   * 返回更新后的 buffer

2. **扩展 server-office.js**

   * 封装 worker 调用

   * 提供 `editAddNode()`, `editRemoveNode()`, `editMoveNode()`

### 第三阶段：UI 扩展

1. **工具栏新增按钮**

   * "添加节点" 下拉菜单（text/container/image/audio/video/url/asset）

   * "删除节点" 按钮

   * "添加页面" / "删除页面"

2. **节点选择器面板**

   * 树形展示当前页面结构

   * 显示节点 ID 和类型

   * 支持点击选中

   * 支持拖拽排序

3. **完整属性编辑器**

   * 布局：width, height, min/max, margin, padding, gap

   * 定位：translateX/Y, rotate, scale

   * 边框：borderWidth, borderColor, borderStyle, borderRadius

   * 背景：backgroundColor, shadow

   * 文本：fontFamily, size, color, weight, style, lineHeight, align

   * Flex：direction, justify, items, wrap

4. **交互功能**

   * 右键菜单（删除、复制、粘贴）

   * 拖拽移动节点

   * 快捷键支持

***
